# 神经殊异与六类身体健康状况：共现证据与争议

> 本页提供一般性健康信息，不用于个体诊断，也不能替代专业评估。

本页介绍六类在神经殊异社群中经常被讨论的身体健康状况：

1. 关节过度活动、关节过度活动谱系障碍（HSD）与超活动型埃勒斯-当洛斯综合征（hEDS）；
2. 体位性心动过速综合征（POTS）；
3. 肥大细胞活化综合征（MCAS）；
4. 多囊卵巢综合征（PCOS）；
5. 甲状腺疾病；
6. 自身免疫疾病。

每一节都按同一顺序回答：

1. **它是什么疾病或状况；**
2. **可能出现哪些情况，又容易与什么混淆；**
3. **在孤独谱系、ADHD 或其他神经殊异者中有多常见；**
4. **现有数字能说明什么、不能说明什么。**

“可能出现的情况”不是自诊清单。症状相似不表示病因相同，也不表示满足其中几项就能确诊。

## 先看结论

| 身体健康状况 | 它主要涉及什么 | 目前的神经殊异共现证据 |
|---|---|---|
| 关节过度活动、HSD 与 hEDS | 关节活动范围、结缔组织相关症状和功能影响 | **存在关联信号，但研究经常混合不同诊断** |
| POTS | 直立时心率和自主神经调节 | **没有可靠的神经殊异人群共现率** |
| MCAS | 反复、系统性的肥大细胞介质释放 | **没有可靠的神经殊异人群共现率** |
| PCOS | 排卵、雄激素及代谢健康 | **可能相关，但本人共现研究较少且异质** |
| 甲状腺疾病 | 甲状腺结构、功能或自身免疫 | **结果不一致，没有稳定的合并患病率** |
| 自身免疫疾病 | 免疫系统异常针对自身组织的一组疾病 | **广义类别可能增加，具体疾病差异很大** |

## 关节过度活动、HSD 与 hEDS

### 它们是什么

关节过度活动（joint hypermobility）是一个或多个关节活动范围超过通常预期。它可以只是身体特征，并不自动构成疾病。

关节过度活动谱系障碍（hypermobility spectrum disorder, HSD）用于描述有关节过度活动及相关症状或功能影响、又没有其他疾病能更好解释的情况。

超活动型埃勒斯-当洛斯综合征（hypermobile Ehlers-Danlos syndrome, hEDS）是埃勒斯-当洛斯综合征的一种临床诊断。当前 2017 标准同时考虑全身性关节过度活动、其他结缔组织表现、肌肉骨骼问题、家族史和排除其他诊断。[GeneReviews](https://www.ncbi.nlm.nih.gov/books/NBK1279/)

三者不能互换：

| 名称 | 是什么 | 不表示什么 |
|---|---|---|
| 关节过度活动 | 身体体征或特征 | 不自动表示有 HSD 或 hEDS |
| HSD | 有症状和功能影响的临床框架 | 不是简单的“轻型 hEDS” |
| hEDS | 需要满足完整标准的临床诊断 | 不能只凭柔韧性或 Beighton 评分确诊 |

### 可能出现哪些情况

有症状的关节过度活动可能伴随：

- 反复关节疼痛、扭伤、半脱位或不稳感；
- 运动后恢复时间较长；
- 肌肉容易疲劳；
- 本体感觉和动作控制困难；
- 慢性疼痛及活动参与受限；
- 部分人同时报告胃肠道、直立不耐受或疲劳症状。

这些表现也可能来自运动损伤、炎症性关节病、其他遗传性结缔组织病、神经肌肉疾病、[[发展性协调障碍与其他神经发育共现|发展性协调障碍]]或其他疼痛状况。动作笨拙、低肌张力或慢性疼痛本身不能反推出 hEDS。

### 在神经殊异者中有多常见

[[BaezaVelascoEtAl2025|Baeza-Velasco 等（2025）]]纳入 20 篇有关孤独谱系、关节过度活动、HSD 和 EDS 的论文：

| 研究结果 | 合并比例 |
|---|---:|
| 孤独谱系样本中的一般关节过度活动 | 22.3% |
| 只看临床评估关节过度活动的研究 | 31% |
| 孤独谱系样本中的 HSD／EDS 合并标签 | 27.9% |
| 只看临床评估 HSD／EDS 的研究 | 39% |

这些比例不是“中国大陆孤独谱系者的 hEDS 患病率”。研究在年龄、招募方式、诊断标准和性别构成上差异很大，且常把一般关节过度活动、HSD、hEDS 或其他 EDS 放在一起。临床样本还可能集中收录已经有疼痛或身体症状的人。

### 目前怎样理解

现有资料支持：孤独谱系与一般关节过度活动、HSD 或 EDS 之间**可能存在群体关联**，身体主诉值得被认真评估。

目前不能确定：

- 严格 2017 标准下 hEDS 在神经殊异者中的真实患病率；
- 关节过度活动与神经殊异之间的因果方向；
- 某个体是否因为孤独谱系或 ADHD 而需要接受 hEDS 诊断。

## POTS

### 它是什么

体位性心动过速综合征（postural orthostatic tachycardia syndrome, POTS）是一种慢性直立不耐受综合征。直立后出现持续性心率过度增加，同时存在直立时加重的症状，并需要排除会造成类似心动过速的其他情况。[诊断综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC8920526/)

POTS 不等于：

- 偶尔站起来头晕；
- 一次心率变快；
- 焦虑时心悸；
- 所有形式的自主神经功能障碍。

### 可能出现哪些情况

直立时可能出现：

- 心悸、头晕、眼前发黑或接近晕厥；
- 乏力、运动耐量下降；
- 注意或思考暂时变困难；
- 恶心、震颤、出汗变化；
- 坐下或躺下后症状改善。

贫血、脱水、发热、甲状腺功能异常、心律失常、药物作用、长期卧床后的体能下降及其他循环或内分泌问题都可能造成类似表现。焦虑也可能伴随心悸，但不能只凭焦虑史否定真实的体位相关症状。

### 在神经殊异者中有多常见

目前没有可靠的孤独谱系或 ADHD 人群 POTS 合并患病率。

[[CsecsEtAl2022|Csecs 等（2022）]]比较 109 名有孤独谱系、ADHD 或 Tourette 综合征诊断的成人与一个较小的比较组，发现神经殊异组报告更多直立不耐受症状。但研究没有对所有参与者按统一流程确诊 POTS，因此不能从中计算 POTS 共现率。

已有 hEDS／HSD 与 POTS 的研究也不能间接证明神经殊异与 POTS 的比例。即使“神经殊异与关节过度活动”及“关节过度活动与 POTS”分别存在关联，也不能自动推出神经殊异者的 POTS 风险。

### 目前怎样理解

可以写：

> 部分神经殊异者会报告直立不耐受症状，这些症状需要按一般医学标准评估。

不宜写：

> POTS 是神经殊异者已经证实的常见共病。

## MCAS

### 它是什么

肥大细胞活化综合征（mast cell activation syndrome, MCAS）是反复发生系统性肥大细胞活化的临床综合征。

专业共识通常同时要求：

- 发作符合系统性肥大细胞介质释放的临床模式；
- 发作期间存在可复核的客观介质变化；
- 针对肥大细胞介质的治疗能够改善相应发作。

任何一项单独存在都不足以确诊。[AAAAI 工作组报告](https://pubmed.ncbi.nlm.nih.gov/31476322/)

### 可能出现哪些情况

发作可能涉及两个或更多系统，例如：

- 皮肤潮红、瘙痒、荨麻疹或血管性水肿；
- 喘鸣或呼吸道症状；
- 腹痛、腹泻、恶心或呕吐；
- 心动过速、低血压、接近晕厥；
- 严重时出现全身性过敏反应。

这些表现并不特异。食物或药物过敏、慢性荨麻疹、哮喘、胃肠道疾病、POTS、药物不良反应、感染及其他内分泌或免疫问题都可能表现相似。

疲劳、脑雾、胃肠道不适、皮肤敏感或心悸的宽泛组合，不能单独证明 MCAS。

### 在神经殊异者中有多常见

目前没有使用严格共识标准估计孤独谱系、ADHD 或广义神经殊异人群 MCAS 患病率的可靠研究。

[[FarleyEtAl2025|Farley 等（2025）]]系统检索肥大细胞活化疾病、遗传性 α-类胰蛋白酶血症、POTS 和 EDS 的共现证据。研究筛查 200 条记录、评估 92 篇全文，却没有一项研究完全满足其预设的严格诊断标准。

该综述没有直接研究神经殊异，但它说明网络中常见的“hEDS–POTS–MCAS 三联征”尚不能被当作已经确认的流行病学组合，更不能再把神经殊异加入其中。

### 目前怎样理解

多系统症状是真实且值得评估的。指出 MCAS 证据不足，不是在否定身体体验。

记录时至少写明：

- 每次发作的开始、持续时间和诱因；
- 具体涉及哪些器官系统；
- 发作时有没有可复核的体征或检查结果；
- 过敏、药物、感染和其他疾病等替代解释。

不能依据社群症状表自行建立 MCAS 诊断，也不应因为怀疑 MCAS 而延误对严重过敏反应或其他疾病的常规评估。

## PCOS

### 它是什么

多囊卵巢综合征（polycystic ovary syndrome, PCOS）是一种涉及排卵、雄激素和代谢健康的综合征。

成人诊断通常综合考虑：

- 排卵功能异常；
- 临床或生化高雄激素表现；
- 多囊卵巢形态或适用的替代指标；
- 排除其他能够解释相关表现的疾病。

“卵巢有多个囊肿”不是 PCOS 的必要日常解释；多囊卵巢形态本身也不等于 PCOS。青少年的诊断要求更加谨慎。[2023 国际循证指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC10505534/)

### 可能出现哪些情况

PCOS 可能涉及：

- 月经稀发、不规律或较长时间不来月经；
- 排卵困难或生育相关问题；
- 多毛、痤疮或雄激素相关表现；
- 胰岛素抵抗、糖脂代谢或体重相关问题；
- 睡眠、身体形象、焦虑或抑郁方面的额外负担。

月经变化也可能与妊娠、能量摄入不足、泌乳素、甲状腺、绝经过渡、药物或其他妇科和内分泌问题有关。参见[[月经PMDD与神经殊异]]和[[精神药物相关高催乳素血症与月经变化]]。

### 在神经殊异者中有多常见

研究需要分成两个不同问题：

#### PCOS 者本人是否更常见孤独谱系

[[KatsigianniEtAl2019|Katsigianni 等（2019）]]合并 5 项相关研究后报告，有 PCOS 的女性本人被诊断为孤独谱系的 OR 为 1.78（95% CI 1.10–2.87）。

这一结果是相对优势比，不是“孤独谱系者中有多少人患 PCOS”。研究间异质性很高（I²=85.4%），说明不同研究结果并不稳定。

#### 母亲 PCOS 与后代孤独谱系

同一 Meta 分析报告，有 PCOS 的母亲，其后代孤独谱系诊断的合并 OR 为 1.66（95% CI 1.51–1.83）。

这是孕期／家族层面的关联，不是母亲本人或孤独谱系者本人的共现率，也不能单独证明 PCOS 或雄激素造成孤独谱系。

### 目前怎样理解

PCOS 与孤独谱系可能存在群体关联，但目前还没有稳定的“中国大陆神经殊异者 PCOS 患病率”。

实际健康评估应从月经、雄激素或代谢表现本身出发，不能因为一个人是孤独谱系或 ADHD 就推定 PCOS。

## 甲状腺疾病

### 它们是什么

“甲状腺疾病”包括多种不同问题：

| 类型 | 示例 |
|---|---|
| 甲状腺功能异常 | 甲状腺功能减退、甲状腺功能亢进 |
| 自身免疫性甲状腺疾病 | 桥本甲状腺炎、Graves 病 |
| 结构性问题 | 甲状腺结节、甲状腺肿 |
| 特定生命阶段问题 | 妊娠期或产后甲状腺功能变化 |

甲状腺抗体阳性、TSH 改变、甲状腺激素改变和临床甲状腺疾病不是同一层级。

### 可能出现哪些情况

不同甲状腺疾病可能出现：

- 疲劳、怕冷或怕热；
- 心率、出汗、震颤或肠道活动变化；
- 睡眠、注意、情绪或活动水平变化；
- 体重和食欲变化；
- 月经改变；
- 颈部肿大或压迫感。

这些表现都很不特异，也可能来自贫血、感染、睡眠问题、抑郁或焦虑、药物、营养状况、月经／绝经过渡及其他身体疾病。不能因为“脑雾”“耗竭”或注意困难就推定甲状腺疾病。

### 在神经殊异者中有多常见

目前没有稳定的孤独谱系或 ADHD 人群甲状腺疾病合并患病率。

现有证据包括两个不同层次：

#### 疾病诊断研究

一项芬兰登记研究比较 4,600 名孤独谱系者和匹配对照，报告孤独谱系者本人被诊断为自身免疫性甲状腺炎的校正 OR 为 2.7。该结果来自单一国家的登记和诊断编码，需要其他人群重复验证。

#### 生物标志物研究

[[LongEtAl2025|Long 等（2025）]]纳入 16 项研究、共 2,399 人。总体上没有发现总 T4、游离 T3、游离 T4 或 IGF-1 的显著组间差异；TSH 合并均值较低。

生物标志物均值不同不等于每个人存在甲状腺疾病，也不能据此定义“孤独谱系甲状腺异常”。

母孕期甲状腺状况与后代神经发育的研究又是第三个问题，不能与本人共现混合。

### 目前怎样理解

现有结果不一致，可以支持“不要把新发身体变化全部归因于神经类型”，但不能支持仅因孤独谱系或 ADHD 身份就进行统一的额外甲状腺筛查。

是否需要检查应依据具体症状、病史、药物、生命阶段和当地临床规范。

## 自身免疫疾病

### 它们是什么

自身免疫疾病是一组由免疫反应异常针对自身组织所致的疾病，不是一个单一诊断。

例如：

- 自身免疫性甲状腺疾病；
- 1 型糖尿病；
- 乳糜泻；
- 炎症性肠病；
- 类风湿关节炎；
- 系统性红斑狼疮；
- 多发性硬化等。

过敏、特应性疾病、免疫缺陷、感染、MCAS 和非特异性“炎症指标”不能全部归入自身免疫疾病。

### 可能出现哪些情况

表现取决于具体器官和疾病，可能包括：

- 持续或反复的关节、皮肤、胃肠道或神经系统问题；
- 不明原因的发热、疲劳或体重变化；
- 特定的内分泌功能异常；
- 炎症指标、抗体或器官功能检查异常。

这些表现依然不特异。单项抗体阳性、疲劳或“容易发炎”的主观体验不能建立自身免疫病诊断。

### 在神经殊异者中有多常见

[[RydzewskaEtAl2021|Rydzewska 等（2021）]]汇总 24 项有关孤独谱系身体健康的系统综述，认为某些自身免疫疾病和特应性疾病可能更常见，但原始研究较少、异质性明显，且成人资料尤其不足。该伞状综述没有给出一个可以代表所有自身免疫疾病的统一患病率。

[[VillarrealEtAl2024|Villarreal 等（2024）]]在美国一个人口出生队列中比较 1,014 名孤独谱系者和年龄、性别匹配参照者：

| 随访中出现首个自身免疫疾病 | 人数 |
|---|---:|
| 孤独谱系组 | 50／1,014 |
| 匹配参照组 | 59／2,028 |

研究报告 HR 为 1.74（95% CI 1.21–2.52）。

这些数字把多种自身免疫疾病合成一个结局，并受诊断编码、医疗接触和具体疾病基础患病率影响。它们不是某一种自身免疫病的个人风险。

### 目前怎样理解

现有资料提示，孤独谱系与“发生至少一种自身免疫疾病”之间存在需要继续研究的群体关联。

不能据此说：

- 孤独谱系本身是自身免疫疾病；
- 所有孤独谱系者都存在免疫异常；
- 某种免疫治疗可以改变神经类型；
- 所有自身免疫疾病都应接受相同筛查。

后续如果建立独立页面，应按乳糜泻、1 型糖尿病、炎症性肠病或自身免疫性甲状腺病等具体疾病分别检索。

## 对中国大陆读者意味着什么

本轮公开检索没有找到能够代表中国大陆神经殊异人群、并为上述六类状况提供可靠共现率的研究。

据此，在中国大陆语境中：

- 不能把欧美专科样本的比例直接当作中国大陆个人概率；
- 也不能因为缺乏本地研究就忽视真实的身体主诉；
- 实际评估仍应依据具体症状、个人基线、病史和中国大陆适用的临床规范；
- 孤独谱系、ADHD 或其他神经殊异身份既不应成为否定身体疾病的理由，也不应自动成为某种网络热门疾病的诊断依据。

## 何时需要及时评估

首次或反复晕厥伴受伤、胸痛、明显呼吸困难、疑似严重过敏反应、持续循环状态异常、快速出现的神经系统变化，或与个人平常状态相比迅速而显著的身体和功能下降，需要及时联系所在地急救或急诊服务。

这不是完整分诊清单。年龄、孕期、既往疾病和药物都可能改变风险判断。
