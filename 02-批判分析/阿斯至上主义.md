# 阿斯至上主义

**阿斯至上主义**（Aspie Supremacy）指把被视为“阿斯”（Aspie，源于 Asperger’s）或“高功能”的一部分孤独谱系者，评价为比其他孤独谱系者、乃至非孤独谱系者更优越的立场。它以智力、语言表现、社会用途或经济价值划分人的高低，并据此区分谁值得接纳、支持和尊重，以及谁有资格代表或引领他人。相关批评将这种价值等级与[[健全中心主义]]联系起来，关注对部分人的肯定怎样与对另一些人的排斥并存（[Baggs，2010](https://ballastexistenz.wordpress.com/2010/03/07/aspie-supremacy-can-kill/)；[[deHooge2019|de Hooge，2019]]）。

## 讨论脉络

Mel Baggs 在《Aspie Supremacy can kill.》（2010）中，区分了宣称孤独谱系者普遍优越的立场，与把“阿斯／高功能”置于其他孤独谱系者之上的等级。后者在 Baggs 看来更容易与既有权力结合：它接受社会对某些残障者的贬低，只要求把被认为更有价值的一部分人排除在贬低之外。批评由此涉及社群内部的等级及其与社会待遇的关系。

[[deHooge2019|de Hooge（2019）]]将这种等级放在白人男性气质、经济用途与“*充分具有人性*”的理想中分析。她以医学文本、倡权组织宣传和文化作品开展定性研究，考察同一套规范怎样一面贬低孤独谱系者，一面推崇某种“阿斯”形象。历史与文化分析将讨论从个别人的优越感，延伸到塑造这种优越地位的社会标准。

## 能力与价值等级

在阿斯至上主义中，具体能力的差异被转化为人的价值与地位差别。智力、语言流利程度或职业成就被用来证明某些人整体上更优越，特殊才能又成为获得社会接纳和支持的理由。对一部分人的肯定，因而可以与对其他孤独谱系者和残障者的贬低同时出现（Baggs，2010；de Hooge，2019）。

阿斯至上主义对部分差异的推崇，可以保留既有的[[神经规范性]]：符合主流理想、甚至被认为超越主流的表现受到赞赏，其他感知、沟通或依赖方式仍处于较低位置。

## 历史与文化中的等级建构

### 社会用途与优生逻辑

de Hooge（2019）通过 Hans Asperger 的历史，讨论对部分儿童才能的赞赏与对另一些儿童的贬低之间的联系。她转述 Silberman（2015）以密码破译等潜在用途说明部分儿童价值的叙述，将社会用途视为当时生命价值筛选的重要依据。

她将这种价值筛选与纳粹时期的优生政策联系起来，批评以“*有用*”决定谁应受到保护的逻辑，并由此讨论当代以社会贡献作为支持与承认条件的评价方式。更广泛的历史背景见[[优生学]]与[[残障权利运动史]]。

### 媒体理想与交叉性

在文化作品中，社会用途与能力等级又可以体现为某种受到推崇的角色形象。de Hooge 以 BBC《Sherlock》中的 Holmes 和《The Rosie Project》中的 Don Tillman 为例，分析理性、技术才能、职业地位及男性特权怎样被组合为“*阿斯*”形象。她特别区分了需要理解的沟通差异，与因角色被视为天才而获得宽容的伤害性行为。

这一分析也揭示了等级的性别与种族维度：相似的非典型表现可以因人物所处的位置而得到不同评价。论文讨论了“*极端男性脑*”等理论与这种文化形象的联系，以及白人男性经验在孤独谱系描述中占据的中心位置。相关讨论见[[神经多样性与交叉性]]。

de Hooge 还借此讨论后人类主义。将某些人想象为超越普通人的理性机器，仍可能延续对理性、控制和白人男性气质的推崇；形象上的“超越”因而可以与既有的价值等级共存。更具体的论证见[[deHooge2019]]。

## 功能标签与选择性承认

历史与文化中受到推崇的能力，也会成为评价支持需要和发言资格的标准。de Hooge（2019）讨论了功能标签的双重作用：一个人可能因被视为“*高功能*”而难以获得支持，也可能因被视为“*低功能*”而难以被承认为可信的发言者。标签的使用由此同时影响支持的提供和对当事者知识的承认。相关问题见[[知识不正义]]。

Baggs（2010）强调，这种内部等级的后果取决于它与社会权力怎样结合。以接近正常标准作为值得保护的理由，可以使较远离标准的人继续被排斥。其批评因此涉及机构照护、免于伤害和获得支持的实际条件。

## 与神经多样性范式的区别

**阿斯至上主义不等于[[神经多样性范式]]。**[[PellicanodenHouting2022|Pellicano 与 den Houting（2022）]]将所有人的尊严与平等尊重作为范式的基本立场，明确包括支持需要最高、最复杂的人；这种尊重独立于差异能否带来集体益处。阿斯至上主义则将某些人的能力优势转化为更高的社会地位。二者的分歧在于，接纳与权利是否以才能和社会用途为条件。

发展个人才能与平等权利分别涉及不同层面的价值。[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]指出，个人可以从擅长的事情中获得自尊、快乐和机会，也应有条件向教师、雇主等人展示能力；但一项能力在特定任务中的价值，不能代替每个人作为人的平等价值。[[ShawEtAl2025|Shaw 等（2025）]]进一步强调，优势与困难取决于个人差异同情境、制度及期待的关系。这使才能发展与环境调整、消除歧视及当事者参与共同成为支持的一部分。

下表概括两种立场在才能、支持与参与上的不同依据；制度与资源层面的分析还参考了[[JonesOrchard2024|Jones 与 Orchard（2024）]]对选择性包容的批评：

| 比较方面 | 神经多样性范式的平等立场 | 阿斯至上主义的等级立场 |
|---|---|---|
| 人的价值 | 不同能力和支持需要者具有平等地位 | 以智力、功能标签或社会用途划分人的高低 |
| 才能发展 | 依个人兴趣、意愿与需要发展能力 | 将特殊天赋或“超能力”作为值得接纳的理由 |
| 支持依据 | 回应具体困难、支持需要与自主选择 | 优先承认能展示优势或预期贡献者的需要 |
| 制度与资源 | 改善不同支持需要者获取资源及参与的条件 | 以才智或预期贡献筛选值得接纳的人，保留对其他人的排斥 |
| 经验与发言权 | 不同沟通方式者都能参与对自身处境的解释 | 按智力或语言表现分配可信度与解释资格 |
| 社群代表与领导 | 通过成员参与、授权和问责形成代表关系 | 把自认的高智商作为引领其他成员的资格 |

### 历史边界与制度实践

Jones 与 Orchard（2024）则从早期文本出发，对神经多样性的包容主张提出质疑。她们重读 Singer（1999），指出其中对“*阿斯*”身份的肯定，伴随着同有智力残障的孤独谱系儿童拉开距离；以先天神经差异解释身份，也可能在减轻部分人污名的同时，保留对其他精神残障者的贬低。她们据此批评将相关历史简化为从错误认识走向科学接纳的进步叙事，并质疑以“神经”为基础的政治能否兑现其包容主张。

[[JonesOrchard2024|Jones 与 Orchard（2024）]]将类似的价值区分放到神经多样性进入主流机构的过程中讨论。她们借用 Mitchell 与 Snyder（2015）的“**撇脂**”（creaming）概念，描述机构接纳少数更符合既有社交、表达和生产要求的残障者，同时维持其他人所面对的排斥。对“*特殊天赋*”的推崇由此具有制度作用：少数人的成功成为展示包容的依据，而支持资源匮乏、贫困及制度性暴力仍然持续。这种接纳具有条件性，得到承认的人也仍可能遭遇健全中心主义伤害。

这一分析将少数人的地位改善与残障群体整体处境联系起来。纳入部分成员，与改变制度对不同支持需要者的待遇，涉及不同层面的变化。[[神经撒切尔主义]]侧重分析市场价值对接纳的筛选，[[庸俗版神经多样性]]讨论理念语言与实践目标的关系；阿斯至上主义则着重揭示其中按能力划分人的高低的逻辑。更广的政治经济分析见[[神经多样性与资本主义]]。

## 中国语境中的相关讨论

[[LaoZhu2024|刘宇翀与朱绘霖（2024）]]在中文孤独症术语综述中，讨论了类似的价值区分：被称为“阿斯伯格／轻微孤独症”的人被描述为具有优势乃至天赋、获得支持后能够成为社会瑰宝，有复杂沟通和生活支持需要的人则被描述为缺乏优势的负担。作者将这种区分与健全中心主义及当事者主体性的受损联系起来。

在这类叙事中，阿斯标签同时承载身份与价值判断，对部分人的肯定以其可展示的才能为依据。将神经多样性理解为肯定和开发“超能力”，也使支持目标集中于优势的发掘与展示。Chapman 与 Fletcher-Watson（2026）指出，这类表述可能强化神经多样性排斥有学习障碍者的印象；对语言的表面接纳，也容易给人制度与实践已经改变的印象。书中使用的英国术语 learning disability，具体见[[神经多样性与学习障碍]]。

## 代表性与社群团结

价值等级还可以从对支持对象的筛选，延伸到社群内部的知识权威和代表关系。以自认的“*高智商阿斯*”身份论证领导资格的主张，将智力评价与更充分的政治理解相联系，并把其他神经殊异者置于等待引领和“觉醒”的位置。在这种关系中，少数成员获得解释共同处境的优先权，其他成员的经验和不同意见则处于从属位置。这是能力评价转化为解释资格的一种表现。

与此相联系，社群参与涉及不同支持需要者获得信息、表达意见和影响共同决定的条件。Chapman 与 Fletcher-Watson（2026）讨论了学者、家长、照护者和有学习障碍者的身份交叠，以及适当支持对自我倡权的作用。共同学习、沟通支持和组织资源能够扩大参与范围，成员授权与问责则关系到领导者的代表资格。

Jones 与 Orchard（2024）进一步将政治评价的重心放在**离制度性权力最远、最接近结构性伤害者**的处境，包括残障与贫困、种族化处境的交叉。代表性由此也涉及这些成员的需要在资源配置和集体行动中占据的位置，将社群内部的参与条件同更广泛的制度待遇联系起来。运动中的相关分歧见[[神经多样性批判与回应]]，共同决定的实践方法见[[参与式行动研究]]。
