# 对神经多样性的批判与回应

**对神经多样性的批判与回应**围绕神经差异应如何被理解、谁能代表相关群体，以及研究和制度应怎样提供支持展开。争论涉及[[神经多样性范式]]的理论主张、[[神经多样性运动]]的倡权实践，也涉及机构采纳相关语言后的实际改变。主要议题包括残障与痛苦、不同支持需要者的参与、身份与诊断边界，以及资源和权力的分配。批评者与回应者在这些问题上可能具有共同目标，同时对困难的解释、改变的方向和实现方式存在分歧（[[Kapp2020|Russell，2020，第21章]]；[[Hughes2021|Hughes，2021]]；[[NeemanPellicano2022|Ne’eman 与 Pellicano，2022]]）。

## 差异、支持目标与决定权

怎样理解神经差异，会影响人们认为哪些改变值得追求。围绕痛苦与残障的争论，因而直接涉及支持的目标：是消除某类差异、减轻具体困难，还是改变造成排斥的环境？[[Hughes2021|Hughes（2021）]]质疑把孤独谱系一概视为不具有内在伤害性的差异；[[Dwyer2022|Dwyer（2022）]]则提出结合个体特点与环境、以生活质量和当事者偏好判断支持方式的路径。这些分歧关系到医疗、教育和照护应当怎样回应个人需要。

支持目标的形成又涉及决定权：谁能解释当事者的需要，谁能影响服务安排？[[Kapp2020|Russell（2020，第21章）]]对运动代表性的讨论，将注意力引向不同沟通方式和支持需要者能否参与倡权。[[NeemanPellicano2022|Ne’eman 与 Pellicano（2022）]]则把神经多样性放在残障政治中理解，将具体特征的支持与当事者参与联系起来。由此，差异的解释与运动中的代表关系、实际参与紧密相连。

当机构将神经多样性纳入政策和项目时，这些问题进一步表现为准入标准与资源分配。[[JonesOrchard2024|Jones 与 Orchard（2024）]]批评机构可能选择性接纳更符合既有要求的人，并继续排斥其他精神残障者。评价这类实践，便需要考察哪些人获得支持、哪些人参与决定，以及原有的排斥机制怎样改变。下文分别讨论这些相互关联的争议；运动的组织发展见[[神经多样性运动史]]。

## 残障、痛苦与医疗需要

[[Hughes2021|Hughes（2021）]]将孤独谱系的行为与因果异质性作为批评起点：某些人的困难和伤害，不能完全归于歧视或不公平的社会安排。他质疑把“孤独谱系从来不具有内在伤害性”设为一般主张，也质疑仅因某项特征有害，就把它划到孤独谱系之外、归为共现状况的论证。对于身份解释，他认为把某种特征视为自我的一部分，并不能直接证明它对本人有益。

Hughes 的结论保留了神经多样性事实及平等权利、尊重、支持和参与等运动目标的价值。他主张，这些目标可以建立在权利与福祉的基础上，同时承认个体和社会因素对困难的影响。其批评因此主要针对特定的理论承诺及推论。

回应者提出了不同路径。[[Dwyer2022|Dwyer（2022）]]的互动主义／生态方案同时分析个体特点与环境，以生活质量和当事者偏好判断支持方式；[[ArnaudGibson2025|Arnaud 与 Gibson（2025）]]则以实体抽象原则分析人与诊断的关系，主张身份承认可以与困难和支持需要并存。后者把争论从“差异是否一概有益”转向“是否把神经殊异性理解为应从人身上移除的东西”。

[[NeemanPellicano2022|Ne’eman 与 Pellicano（2022）]]进一步主张，围绕具体特征及其影响讨论支持，避免先把整个人划为适用或不适用神经多样性范式。例如，减少自伤造成的伤害与保留无害的自我调节动作，可以共同成为支持的目标。有关[[去病理化]]、整体治愈、正常化和具体支持的区别，仍需要在实际处境中判断；身份论证也不能代替对某项措施效果和负担的研究。

## 代表性与高支持需要者的参与

Russell（2020，第21章）指出，依靠写作、公开发言和网络联络开展的倡权，可能使无法通过这些方式参与的人较少被听见。她同时记录了家长、非口语倡权者及活动组织者在运动中的不同位置与包容尝试。这涉及谁进入了公共议程、谁能提出目标，以及代为表达与当事者意愿如何联系。

[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]从平等价值出发，批评以智力、学历、语言流利程度或就业能力衡量人的价值。他们也讨论了以“学者型倡权者”与“高支持需要者的家长”为仅有两方的叙述：现实中的神经殊异者、家长和照护者身份可以交叠，学习障碍者也可以在适当支持下参与倡权。这里的 learning disability 采用英国语境，涉及智力与适应功能方面的支持需要，具体术语见[[神经多样性与学习障碍]]。

理论上的平等承认，与组织中的代表性是两个相连的问题。参与需要可及的沟通方式、活动和研究安排、长期支持，以及影响决定的机会。判断某项倡权是否回应了高支持需要者，应考察这些人及其支持网络如何参与目标形成、资源使用和效果评价，而不能仅依据代表者的身份或组织宣言。

## 身份边界、知识与个人选择

Russell（2020，第21章）对“神经典型／神经殊异”的二分和神经生物学解释提出了追问：群体身份有助于形成共同诉求，也可能被使用为固定的内外边界；以神经相似性证明代表资格，还需要面对群体内部经验与需要的差异。她对神经中心主义的分析，关注生物解释如何影响责任、认同和政治承认。

[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]的回应强调，命名[[神经规范性]]能够揭示实际存在的等级关系，并将学校、工作和照护中的安排转化为政治议题。他们同时承认，身份类别被视为固定本质时可能限制解放实践。由此，身份既可以是形成团结的资源，也需要联系历史条件、制度处境与跨群体合作理解。

个人经验也是争议的一部分。[[May2025|May（2025）]]强调，同一特征的意义可能随个人、处境与生命阶段变化；社群接纳与环境改善之后，仍有人希望改变某些特征。身份承认、个人改变愿望和公共服务的普遍目标，需要分别讨论。如何容纳不同叙述、如何处理成员间的压力与冲突，是实际社群关系中的问题。

[[StennerEtAl2025|Stenner 等（2025）]]让十位神经殊异研究者共同生成陈述、完成 Q 排序并讨论结果，识别了他们对运动含义和目标的不同理解。这项集体反思研究提供了一种表达和比较分歧的方法。作者明确其研究对象是研究小组自身的观点，因此结果能够说明组内的差异与共识，不能据此判断整个运动是否存在群体压力或排斥经验。

## 诊断、自我认同与支持资格

诊断与自我认同的争议涉及几个不同的问题：人们怎样理解自己，临床分类怎样识别某种状况，社群怎样决定参与边界，以及服务项目怎样认定支持需要。Russell（2020，第21章）讨论了完全依赖专业诊断或完全依赖自我认同时分别面临的群体边界问题。

[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]将自我认同的扩展联系到对自身经验的重新理解、诊断可及性和环境造成的失能，并质疑将所有解释权交给临床专业人员。他们也保留了医疗评估和专业支持的作用。这一政治与概念解释有助于分析谁拥有命名权，具体诊断的准确性、某项自我判断是否可靠，以及诊断数量变化的原因，则需要相应研究。

同样，承认求助者面临的困难，与确定某个项目的资格和资源安排，需要不同层面的判断。[[NeemanPellicano2022|Ne’eman 与 Pellicano（2022）]]将神经多样性放回残障权利与支持的脉络；[[神经多样性与残障]]进一步讨论了诊断、身份和制度资源的联系。诊断数量本身不足以说明某项权利要求是否正当，也不能直接确定谁应优先得到何种服务。

## 主流化、收编与结构性改变

[[JonesOrchard2024|Jones 与 Orchard（2024）]]对已发表学术论述和机构实践提出了较强的政治批判。他们认为，将神经差异理解为中性或进步的身份资源，却缺少对精神残障历史及现实制度的关注，可能使神经多样性与残障政治脱节。在他们的分析中，机构可以选择性接纳符合既有社会价值的少数人，同时维持对其他精神残障者的排斥；他们借助“撇脂”（creaming）概念解释这种筛选。

这一批评关心的不只是用词，也包括贫困、种族、制度暴力和社会价值如何交织。作者据此追问，神经多样性为离制度权力最远、最接近结构性伤害的人做了什么。其分析范围是特定的学术论述与机构运用，需要与具体组织、政策和社群的实践对应理解。

[[NeemanPellicano2022|Ne’eman 与 Pellicano（2022）]]也警惕以新术语与更广泛残障社群脱节的风险。[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]则用[[庸俗版神经多样性]]分析机构更换语言、却延续原有目标和权力安排的现象。他们强调，评价实践需要考察其基本目标与实际运作，也应注意那些没有采用神经多样性术语、却能支持平等与自主的实践。

这些回应提供了批评机构实践的标准，实际效果仍需看资源、准入、照护与决定权怎样改变。对优秀个体或特殊天赋的宣传，只有与不同支持需要者的生活机会和集体保障联系起来，才能回应选择性承认的问题。相关政治经济分析见[[神经撒切尔主义]]与[[阿斯至上主义]]。

## 社群研究与实践检验

[[Dwyer2025|Dwyer 等（2025）]]对 504 名孤独谱系者及其他社群成员的混合方法研究发现，运动支持度与更反对正常化目标、更支持社会改革和支持性环境相关；支持者对部分适应技能目标仍有一定支持。研究说明，对某个模型的概括性表态，可以与对具体支持的细致判断并存。

该研究的参与者主要来自较富裕英语国家，整体较为高学历，且高支持需要者较少：其中七名孤独谱系参与者有智力障碍，五名为非口语者；神经多样性支持者也更可能参加。作者指出，研究本身收集复杂、丰富资料的方式降低了可及性。这一局限使代表性成为研究设计的实际问题，也限制了以调查结果概括整个社群的范围。“强／弱”社会模型比较中的后一组人数较少，未检出显著差异也不足以证明观点相同。

[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]将共同生产视为改变知识与实践关系的路径，使研究者、当事者、临床人员及其他参与者共同影响问题和目标。[[参与式行动研究]]提供了进一步讨论这种参与关系的专题。概念论证、社群态度研究和实践效果评价分别回答不同问题，它们的联系在于让具体需要、实际参与和制度后果进入争论。
