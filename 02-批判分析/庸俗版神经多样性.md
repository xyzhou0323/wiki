# 庸俗版神经多样性

**庸俗版神经多样性**（neurodiversity-lite），又称“轻量版神经多样性”或“伪神经多样性”，是对采用神经多样性语言或部分概念，却未将人的尊严、自主决定和平等参与落实于支持目标与实践的批判性称谓，具体可能表现为商业利用、主流收编、目标扭曲等形式。相关批评关注用语和组织形象发生改变时，原有的正常化目标、权力关系及资源分配如何继续运作（[Neumeier，2018](https://rewirenewsgroup.com/2018/02/09/siri-love-problem-neurodiversity-lite/)；[[denHouting2019|den Houting，2019]]；[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson，2026]]）。

## 术语历史

[[Shain-M-Neumeier|Shain M. Neumeier]] 在2018年的《‘To Siri With Love’ and the Problem With Neurodiversity Lite》中使用这一称谓，以育儿回忆录引发的争议为背景，批评公众表达中的接纳与对身体自主、基本尊严的忽略并存。[[denHouting2019|den Houting（2019）]]随后在《Autism》社论中引用 Neumeier，将其解释为借用运动辞令却未充分理解范式基础假设的现象，并指出研究者、专业人员、家长及孤独谱系者都可能采用这种简化理解。

此后的研究从接纳边界和支持目标等角度继续使用这一概念。[Botha 与 Cage（2022）](https://doi.org/10.3389/fpsyg.2022.1050897)讨论了神经多样性只被用于肯定特定“一类”孤独谱系者的情形；[[Dwyer2025|Dwyer 等（2025，2024年先行发表）]]则结合社群成员的回答，考察对运动的支持与社会改革、干预目标之间的关系。

随着神经多样性进入学术与商业领域，制度收编也成为相关讨论的一项主题。[Chapman（2025）](https://substack.com/@neurodiversityandcapitalism/p-162761695)讨论了学术机构怎样吸收神经多样性乃至“批判”语言；[[Srinivasan2025|Srinivasan（2025）]]在“神经多样性2.0”框架中分析企业友好的简化叙事；[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]进一步整理了表面改名、蓄意利用及其知识和组织条件。这些讨论共同把语言上的接纳，放到实际支持、平等价值和决定权中考察。

## 典型表现

庸俗版神经多样性可以表现为组织实践中的表面变革、对相关语言的主动利用、传播中的片面理解，以及以市场价值为条件的接纳。下列四种表现可以在同一实践中交叠。

### 1. 表演性变革

表演性变革是指在遵循常态范式的体系内使用“神经多样性知情”（neurodiversity-informed）等用语，但未发生根本性变革，具体可能包括：

- 进步人士错误地认为善意加上新术语就等同于有意义的变革；
- 主流组织为“与时俱进”以最小让步重新贴标签，同时回避更根本的变革。

Chapman 与 Fletcher-Watson（2026）给出一个虚构例子：一个临床路径自称“神经多样性知情”，但实际上限制诊断数量（基于担心“太多”成人寻求诊断），诊断后仍提供神经规范性治疗。学校或职场可能声称自己神经多样性友好，但并没有提供任何便利措施或实际支持。

这种落差也体现在干预目标上。[[Dwyer2025|Dwyer 等（2025）]]提出，庸俗版神经多样性可能类似于去除了病理化语言的医学模型：一方面庆祝神经认知差异，另一方面仍推行[[掩饰与伪装]]，强化[[神经规范性|神经典型的社会规范]]。措辞发生了变化，支持仍以接近常态为目标。

[[PearsonEtAl2026|Pearson 等（2026）]]记录了受访者对**以“正确”术语掩藏偏见**的观察：恰当用语可以形成尊重差异的形象，同时与[[健全中心主义]]实践并存。这里的表演性体现在语言所表达的尊重与实际对待方式之间。

[Gibson 等（2026）](https://doi.org/10.1177/10443894251407390)的受访者认为，一些用神经多样性语言描述自身工作的机构，仍抵制当事者提出的实践改变。作者也记录了社群成员仅承担象征性咨询角色的经历，指出形式上的参与可能缺少对日常实践的实际影响。

### 2. 操纵与歪曲

对神经多样性语言的借用，还可能成为主动维护既有利益的手段。[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]将为私利而蓄意利用或歪曲相关理念，列为另一种形式，具体可能包括：

- 商业包装：为了商业利益使用相关术语，使既有服务显得更可接受，从而获取客户信任；
- 以虚假陈述否定神经多样性运动，阻碍倡权活动。

作者举出的可能情形是：私人执业者将客户称为“神经多元”群体，并把剥削性或伤害性的“治疗”包装为“神经多样性知情”，使其在担忧的家长眼中显得更可接受。作者也批评以运动不包容智力障碍者的笼统断言否定其倡权（详见 [[神经多样性与学习障碍]]），或将神经多样性倡权者塑造成“强大游说团体”而非边缘化少数群体，以抵制相关倡权活动。

### 3. 运动的误解与扭曲

随着神经多样性概念不断传播，一些个人和组织可能在未充分接触运动历史、理论和政治背景的情况下，将简化或片面的表述理解为神经多样性本身。例如，将神经多样性主要理解为“**超能力**”“**只是不同而不是残障**”或“**发掘优势**”，而忽视**残障权利和社会正义**等诉求。这类理解也可能由自认支持神经多样性运动的人继续传播。

[Botha 与 Cage（2022）](https://doi.org/10.3389/fpsyg.2022.1050897)指出，神经多样性的语言和接纳可能只延伸到特定“一类”孤独谱系者，而人的价值仍按智力、独立性或社会贡献来衡量。这样的**有条件接纳**限制了对不以口语沟通者、智力障碍者及高支持需要者的尊重与支持。

[[阿斯至上主义]]（Aspie Supremacy）与庸俗版神经多样性可以交叠：当按能力划分人的价值与神经多样性语言相结合时，可能表现为：

- 采纳神经多样性语言和身份认同，但不深入参与运动的平等和解放原则
- 将认知能力和社会“价值”作为争取门票的基础
- 排斥智力障碍等最边缘化的群体

这些片面理解还会反过来影响公众对运动的认识。当所接触到的“神经多样性”主要围绕超能力展开时，“神经多样性排斥智力障碍者”等批评，便可能从部分实践中获得支持。Chapman 与 Fletcher-Watson（2026）据此讨论了表面接纳如何妨碍运动目标的落实。

### 4. 神经撒切尔主义

在企业和市场中，选择性接纳可以表现为以生产力和利润衡量神经殊异者的价值。[[神经撒切尔主义]]（Neuro-Thatcherism）是 [[Robert-Chapman]] 创造的概念，指在新自由主义条件下，将神经多样性倡权**系统性收编**为商业导向的“超能力”开采计划，名称来自英国的撒切尔主义（Thatcherism）。

在这一过程中，神经殊异从“需要修复的缺陷”被重新定义为“可开采的生产力资源”，差异能否带来**市场竞争优势**成为接纳的条件：

- 孤独谱系特征被重构为“模式识别天赋”“超专注力”——只在产生经济价值时被肯定
- “神经多元劳动力”话语暗含的逻辑是：雇用神经殊异者不是因为权利平等，而是因为竞争优势
- 由此产生双重排斥：对无法在市场中“增值”者的排斥，以及对“残障”语言的拒绝——转向“神经多元”以回避残障的政治性

[[Srinivasan2025|Srinivasan（2025）]]指出，突出超专注、创造力等可市场化特质的企业友好叙事，会忽视优势难以货币化或支持需要较复杂者。

[Risberg 与 Corvellec（2026）](https://doi.org/10.1108/EDI-09-2025-0611)分析了三家专门推动神经多样性职场包容的咨询机构的网站。这些机构向雇主宣传，雇用神经殊异员工能够提高效率、促进创新或更快地解决问题。作者肯定这些机构帮助部分人就业的作用，同时指出，其宣传把包容建立在商业收益之上：符合企业期待的人得到肯定，难以展示相应商业优势者则被置于边缘。这里的**包容门槛**，就是神经殊异者需要先证明自己的差异能够为企业带来收益，才能获得这类就业话语的认可。

## 形成条件

上述现象的形成，涉及新概念怎样进入实践，以及组织在采纳概念时保留哪些目标和利益安排。相关论述主要从知识传播与制度激励两方面解释这种落差。

### 1. 知识与传播的可及性

神经多样性的学术与政治资源分布在期刊、书籍、博客、公开演讲和社群实践等多种载体中。Chapman 与 Fletcher-Watson（2026）指出，惯常的生物医学数据库检索会遗漏这一知识积累的重要部分；付费墙、专业术语以及缺少阅读时间和资源，也限制了从业者与家庭对相关论述的接触。由此，容易传播的新词可能比支撑它们的历史、伦理与政治讨论更快进入服务和研究。

当专业机构主要通过既有学术渠道认识神经多样性时，当事者在社群中积累的知识容易受到忽略。对新术语的接触与对其政治、伦理背景的理解，因而可能脱节。这也涉及[[知识不正义]]与[[神经多样性与民主研究|民主研究]]所讨论的知识权威问题。

### 2. 制度激励与选择性吸纳

语言更新可以在既有组织目标和工作流程内完成，改变支持目标、评估标准与决定权则涉及更深的制度调整。Chapman 与 Fletcher-Watson（2026）区分了善意者误把改名视为变革，与组织在外部压力下选择最小让步的情形；其分析将理解上的局限与组织的利益安排联系起来。

这种选择性吸纳也可以发生在学术领域。Chapman（2025）所称的第一波主要指心理学和精神病学中改变措辞而保留原有承诺的做法；第二波则涉及人文学科中激进或“批判”语言的采纳。在他的分析中，资助、出版机会和研究声望可以使批评本身成为职业资源，而实际行动仍优先维护学术地位与职业利益。

既有评价标准还会影响哪些人首先得到承认。[[JonesOrchard2024|Jones 与 Orchard（2024）]]借用 Mitchell 与 Snyder（2015）的“撇脂”概念，分析神经多样性主流化中少数较符合既有要求者获益，与其他残障者持续面临资源匮乏和结构性伤害的关系。她们的批评也追溯到早期文本与理论基础，范围比对语言表面采纳的批评更广；相关争论见[[神经多样性批判与回应]]，政治经济背景见[[神经多样性与资本主义]]。

## 实证研究

相关研究分别考察人们怎样理解神经多样性、如何评价当事者，以及机构怎样组织服务和就业。它们为上述批评提供了不同类型的材料：

| 研究 | 材料与方法 | 与本概念相关的发现 |
|------|------------|--------------------|
| [Dwyer 等（2025）](https://doi.org/10.1177/13623613241273029) | 混合方法调查504人，包括278名孤独谱系者和226名非孤独谱系者 | 开放回答中，前者更常自发提及社会改革及支持神经殊异者茁壮成长，后者更关注肯定多样性；明确提示社会改革和支持性环境目标后，两组定量评分没有差异，观点存在广泛重叠。 |
| [Botha 与 Cage（2022）](https://doi.org/10.3389/fpsyg.2022.1050897) | 对195名孤独谱系研究者的调查，编码开放回答中的去人性化、物化与污名化线索 | 当事者参与研究的程度较高，与较少此类线索相关；对人的社会价值的判断常涉及智力和独立性。作者也讨论了公平参与所需的权力和支持条件。 |
| [Pearson 等（2026）](https://doi.org/10.1177/27546330261428235) | 参与者的开放文本回答 | 部分回答指出，恰当术语可能与偏见并存，语言所表达的尊重需要结合实际对待方式理解。 |
| [Gibson 等（2026）](https://doi.org/10.1177/10443894251407390) | 2020—2021年在加拿大安大略省西南部进行的60次访谈 | 受访者认为，部分采用神经多样性语言的机构仍抵制实践改变；研究也记录了象征性社群咨询的经历。 |
| [Risberg 与 Corvellec（2026）](https://doi.org/10.1108/EDI-09-2025-0611) | Specialisterne、Unicus Sweden 和 Neurodiversity in the Workplace 三家神经多样性就业咨询机构的网站分析 | 网站以神经殊异员工能带来的效率、创新等商业优势说服雇主。作者指出，以企业收益为包容理由，也会将难以展示相应优势者置于边缘。 |

这些研究呈现了用语、价值判断与实践之间的关系，尚未测量庸俗版神经多样性的总体发生率。Dwyer 等的样本主要来自富裕英语国家，白人及高教育程度者较多，高支持需要者参与有限；Botha 与 Cage 的自选样本研究不能确定参与和态度之间的因果方向；网站分析揭示的是公开表达的价值标准，内部用工实践仍需其他材料检验。
