# 限制性进食与严重营养风险

限制性进食可以来自感官差异、食欲不足、害怕进食的不良后果、身体疾病、吞咽或疼痛问题、抑郁、紧张症、食物短缺、药物效应或以体重体形担忧为核心的进食障碍。原因不同，支持和治疗路径也不同。

严重营养风险是身体安全问题，不要求一个人已经很瘦，也不要求先满足某项进食障碍诊断。体重、BMI 和外观都不能单独排除脱水、电解质异常、微量营养素缺乏或其他并发症。

## 先区分层级

| 层级 | 可能的情况 | 重点 |
|---|---|---|
| 食物偏好或稳定的选择性进食 | 可接受食物范围较窄，但营养、身体和生活功能相对稳定 | 尊重感官和文化偏好，不因“不够多样”自动病理化 |
| 需要支持的限制性进食 | 摄入种类或总量不足，进餐造成明显困扰或依赖额外支持 | 评估感官、执行功能、身体原因、营养和生活可及性 |
| ARFID 或其他进食障碍 | 达到相应诊断要求并造成身体或社会心理影响 | 正式诊断需完整评估，详见[[感官性选择进食与ARFID]] |
| 急性或严重医学风险 | 严重脱水、营养不良、电解质异常、循环不稳定或器官功能受影响 | 及时医学评估和处理，不等待网络自助方案 |

这些层级不是固定阶梯。一个人的身体风险可以在体重仍处常见范围时出现，也可能因急性疾病、呕吐、吞咽问题或突然摄入下降而快速改变。

## 为什么神经殊异者容易被误读

- 感官性食物限制被称为“挑食”或故意对抗，实际营养影响没有评估；
- 原本体型较大，因此快速体重下降或摄入不足没有被重视；
- 因难以识别饥饿、口渴、恶心或疼痛，身体风险被低估；
- 没有典型体重体形担忧，就错误排除所有进食障碍；
- 因已有 ARFID 或孤独谱系诊断，吞咽、牙科、胃肠道、内分泌或药物问题没有排查；
- 食物价格、烹饪、住房、照护和执行功能障碍被归因于“缺乏动力”。

## 需要同时考虑的原因

| 路径 | 示例 | 评估注意 |
|---|---|---|
| 感官和可预测性 | 味道、质地、温度、气味、品牌或包装变化 | 不以突然撤走安全食物作为治疗 |
| 食欲和身体信号 | 低食欲、饥渴信号不明显、药物影响 | 结合时间线、内感受和身体检查 |
| 害怕不良后果 | 害怕噎住、呕吐、疼痛或过敏 | 排查真实身体经历，不简单归为“想太多” |
| 身体和神经问题 | 吞咽、牙痛、胃肠道疾病、感染、癫痫后状态 | 新发变化需要医学鉴别 |
| 精神运动和情绪 | 抑郁、紧张症、严重焦虑、创伤反应 | 不能只用进食障碍标签解释 |
| 体重体形相关 | 神经性厌食症、神经性贪食症等 | 与 ARFID 的核心动机不同，但可以共现或改变 |
| 环境和资源 | 食物短缺、无法烹饪、学校或工作环境不允许进食 | 支持计划应处理现实障碍 |

## 怎样记录身体风险信息

对专业评估更有帮助的信息包括：

- 能否维持饮水，是否反复呕吐或吞咽困难；
- 最近摄入相对本人平常状态下降了多少、持续多久；
- 尿量、晕厥、胸闷心悸、呼吸、体温、乏力和意识变化；
- 体重和生长轨迹，而不是只看当前一个数字；
- 可接受食物、补充营养和过敏信息；
- 药物、疼痛、胃肠道、月经和急性疾病时间线；
- 已有检查结果及其日期、单位和参考范围。

不建议在公开页面给出一个适用于所有人的最低热量、体重或化验阈值。年龄、生长、疾病、摄入速度和检查方法都会改变解释。

## 什么时候需要及时医学评估

NICE 进食障碍指南建议，对严重电解质紊乱、严重营养不良、严重脱水或器官衰竭早期迹象提供急性医学照护。对读者而言，以下变化意味着不宜只等待常规复诊：

- 无法喝下或留住液体、尿量明显减少；
- 晕厥、意识混乱、进行性虚弱或无法完成基本活动；
- 反复呕吐、明显吞咽或呼吸困难；
- 胸痛、明显心悸、抽搐或快速身体恶化；
- 进食饮水显著下降并伴发热、动作／言语变化或严重精神状态变化；
- 当前自伤或自杀危险。

这不是自诊急症的计分表。出现严重或迅速变化时，应由能够检查生命体征、身体状态和必要化验的医疗人员判断。

## 再喂养综合征不是继续限制的理由

长期或严重营养不足后恢复营养时，少数人可能发生需要监测的代谢和电解质变化，称为再喂养综合征（refeeding syndrome）。风险判断和营养恢复方案属于专业医疗。

担心再喂养综合征不应成为继续不吃、不喝或在家自行制定极低摄入方案的理由。如果存在长期严重限制或身体不稳定，应尽快获得医学评估，由专业团队在避免继续营养不足的同时管理再喂养风险。

## 神经友好的营养和医疗支持

- 保留安全食物和可接受的品牌、质地与温度；
- 将稳定身体状态与扩大食物范围作为可区分的目标；
- 提前解释称重、抽血、心电图和进食支持流程；
- 允许选择是否看见体重数字，避免体重羞辱；
- 提供安静进餐环境、熟悉餐具和可预测安排；
- 使用图片、文字、AAC 或照护者观察补充症状信息；
- 在本人同意和安全允许时，让营养、精神科、儿科／内科及相关专科共同协作；
- 不把强迫、惩罚、撤走全部安全食物或“饿了自然会吃”作为神经友好支持。

## 现有证据能说明什么

[[JamesEtAl2024|James 等（2024）]]纳入 132 项儿童、青少年和年轻成人 ARFID 研究，发现低体重、营养素缺乏和低骨密度等身体问题值得关注；研究同时强调，ARFID 可以出现在整个体重范围，许多有身体并发症的人并不属于低体重。

这项证据不能直接外推到所有成年人，也不能把 ARFID 与所有神经殊异者的限制性进食等同。[[SaderEtAl2025|Sader 等（2025）]]的共现 Meta 分析则说明孤独谱系和 ARFID 研究存在重叠，但样本来源和诊断方法差异较大。

## 中国大陆语境

中国大陆已有儿童青少年 ARFID 评估治疗综述和神经性厌食症专家共识，但专门进食障碍与 ARFID 服务分布不均。急性身体风险可以先由急诊、儿科或内科评估，不应等待专门心理服务。就诊时可说明限制的主要路径、可接受食物和沟通支持需求，避免把所有问题只归入“挑食”或“减肥”。
