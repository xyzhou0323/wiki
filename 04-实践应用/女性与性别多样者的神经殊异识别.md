# 女性与性别多样者的神经殊异识别

女性、跨性别、非二元及其他性别多样者可能在孤独谱系或 ADHD 识别中遇到额外障碍。本页讨论诊断过程中的偏差和可见性，不提出一个固定、同质的“女性型神经殊异”。

## 先分开几个概念

| 概念 | 本页怎样使用 |
|---|---|
| 出生指定性别（sex assigned at birth） | 出生时记录的性别分类，不等于当前性别身份 |
| 性别身份（gender identity） | 一个人对自身性别的理解 |
| 性别表达（gender expression） | 衣着、行为、语言等社会表达，不用于推断身份 |
| 诊断性别比 | 被诊断者中的比例，受真实差异、识别偏差和服务可及性共同影响 |

研究常把 sex 与 gender 混用，也可能只提供二元分类。引用结论时应沿用原研究实际测量的变量，并明确局限。

## 识别偏差可能怎样发生

- 临床原型建立在较多男童样本上，导致不符合原型的表现较难被看见；
- 表面社交模仿、预先排练和隐藏感官或重复行为，使外部观察低估负荷；
- 受限兴趣的内容看似符合年龄或性别规范，强度和功能未被询问；
- 焦虑、抑郁、创伤、进食困难或关系问题被单独处理，而发展模式未被整合；
- 对“乖巧”“懂事”“情绪化”的性别期待改变了家长、教师和临床人员的解释；
- 跨性别或非二元者的身份被错误当作精神症状，或反过来所有困难都被归因于性别压力。

孤独谱系性别差异与掩饰研究支持关注诊断过程可能偏向男性原型，但样本、工具和性别分类均有限。[[CruzEtAl2025]] “女性更会掩饰”是群体研究中的一种趋势，不是判断个体的规则。

## 不应建立“女性症状清单”

把旧的男性刻板印象换成新的女性刻板印象，仍会漏掉许多人。评估更适合询问：某种行为在不同环境中怎样实现、需要付出多少努力、恢复成本是什么，以及从儿童期到当前是否存在一致的发展线索。

社交外观、眼神接触、伴侣关系、学历、职业或成为父母，都不能单独排除神经发育差异。相反，属于女性或性别多样群体也不能降低正式诊断所需的证据标准。

## 性别多样与孤独谱系的交叉

现有综述显示孤独谱系与性别多样之间存在统计关联，但研究定义、样本和测量方式差异较大。[[ReaEtAl2024]] 关联不表示一种身份导致另一种身份，也不能用孤独谱系否定当事人的性别理解。性别肯定支持和神经友好沟通可以同时存在。

## 更公平的评估原则

1. 使用具体、发展性的提问，不只依赖原型印象；
2. 同时询问外在表现、主观负荷、恢复时间和环境支持；
3. 区分神经特质、少数压力、创伤和可独立诊断的精神健康问题；
4. 允许本人选择身份语言、代词和是否有陪同者；
5. 解释工具的样本局限，不以单一量表作结论；
6. 在报告中记录不确定性和仍需支持的问题。

## 中国大陆证据边界

中国大陆关于女性和性别多样成人的代表性诊断路径资料有限，国际样本中的性别表达、医疗可及性和污名经验不能直接外推。编辑时应避免把境外诊断比或社群调查比例换算为中国人数，并保护参与者的性别身份与诊断隐私。
