# 中国大陆神经多样性研究证据索引

本页按问题和证据用途整理中国大陆相关研究，作为可持续维护的证据地图。它把本地数据、国际证据、规范性文件和经验资料分开，帮助编辑回答两个问题：一项结论是否有中国大陆证据，以及境外研究能否合理外推到当前页面所讨论的人群和服务环境。

## 为什么需要单独索引

只写“国内缺少研究”会隐藏已经存在的工作；只要看到中文样本就写成“中国数据”，又会掩盖地区、年龄、服务渠道和测量工具的差异。中国大陆内部也不是单一语境，城乡、地区、教育资源、家庭结构、语言和医疗可及性都会影响研究结果。

因此，本索引以**问题和可外推范围**为单位，不以“国内／国外”二分法代替证据评价。

## 证据分区

| 分区 | 收录内容 | 使用方式 |
|---|---|---|
| A. 中国大陆实证研究 | 明确报告中国大陆地区、样本和方法的研究 | 支持对本地样本的描述；继续检查代表性 |
| B. 中国大陆规范与服务资料 | 法律、指南、共识、统计公报和正式服务文件 | 说明制度与实践背景；不自动当作效果证据 |
| C. 港澳台及中文语境研究 | 来自香港、澳门、台湾或其他中文使用者的研究 | 可提供语言或文化线索；不得静默合并为大陆数据 |
| D. 国际可迁移证据 | 机制、系统综述、服务原则和干预研究 | 说明证据来源，并讨论迁移条件 |
| E. 社群与生活经验资料 | 当事人组织、访谈、倡议文本和灰色文献 | 识别问题和语言偏好；与患病率或疗效证据分开 |
| F. 明确缺口 | 尚未找到、无法外推或未纳入关键人群的问题 | 直接记录“目前不知道什么” |

## 单条记录的最小字段

后续增补研究时，建议至少记录：

| 字段 | 需要写明的内容 |
|---|---|
| 研究问题 | 患病率、测量、机制、体验、服务还是干预效果 |
| 地理范围 | 省市、城乡、机构；不要只写“中国样本” |
| 人群 | 年龄、性别、诊断或识别方式、语言和支持需要 |
| 样本来源 | 社区、学校、医院、互联网或登记系统 |
| 信息来源 | 本人、家长、教师、临床人员、病历或实验测量 |
| 工具版本 | 语言、版本、授权和本地测量证据 |
| 比较与时间 | 是否有比较组，横断面还是纵向 |
| 主要结果 | 效应量、区间和原作者限定；不只摘取显著性 |
| 外推边界 | 不能代表哪些地区、人群或服务场景 |
| 经验参与 | 神经殊异者是否参与研究问题、设计、解释或传播 |
| 更新信息 | 检索日期、来源链接和页面复核日期 |

## 首批已确认的本地证据入口

现有专题已经识别出中国大陆及周边孤独谱系筛查工具的系统综述。[[WangEtAl2020]] 它说明相关研究并非空白，也同时显示工具、样本和统计评价方法存在差异。本索引暂不把单篇量表研究罗列成推荐清单，待按统一字段逐项提取后再扩展。

对于其他共现和服务主题，若当前页面只引用境外研究，应明确标注“未检索到可直接回答该问题的中国大陆代表性数据”，而不是把国际比例换算为中国人数。

## 维护原则

1. 使用中英文数据库和同义词检索，并保存检索日期。
2. 优先链接可核对全文、正式标识和版本的来源。
3. 不按作者单位或中文标题猜测研究地区，要看实际样本来源。
4. 不把香港、澳门、台湾数据静默标成中国大陆数据。
5. 不用单中心临床样本估计全国比例。
6. 发现空白时记录缺口，不用网络讨论度填补证据。
7. 每个主题邀请具有相应生活经验者审阅问题设置和语言。

## 下一步可扩展的证据表

- 成人和晚识别者在中国大陆不同地区的诊断路径与诊断后支持；
- 无口语、智力障碍和高支持需要者的沟通与健康；
- 女性、跨性别和非二元者在中国大陆的识别、医疗与隐私经验；
- 医疗合理调整和沟通工具的实施效果；
- 教育、就业、老龄化和社会保障中的长期结局；
- 中国大陆开发或本地化量表的版本登记；
- 当事人参与式研究和中文社群术语演变。
