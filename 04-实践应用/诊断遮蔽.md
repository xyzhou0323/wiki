# 诊断遮蔽

诊断遮蔽（diagnostic overshadowing）是指临床人员因一个人已有的诊断、残障或身份标签，把新的症状或健康问题不恰当地归因于该标签，从而减少了对其他解释的考虑。典型情形是把身体症状归因于精神障碍，但相似过程也可能发生在神经发育、精神健康和身体健康之间。

诊断遮蔽不是指“第一次判断与最终诊断不同”的所有情况。它强调已有标签、偏见、沟通障碍或服务系统如何过早终止鉴别过程。

## 它可能怎样发生

- 把疼痛、疲乏、行为变化或睡眠恶化笼统归为“就是孤独谱系／ADHD 的表现”；
- 把长期感官敏感或重复行为当作新发焦虑、强迫或精神病性症状；
- 又反过来，把新发抑郁、紧张症、癫痫发作后状态或药物不良反应解释成稳定的神经特质；
- 量表分数先入为主，替代了病史、时间过程、功能变化和体格评估；
- 因沟通方式、较慢加工速度、述情困难或就诊环境过载，使症状没有被充分表达；
- 多个专科分别处理单一问题，没有整合用药、身体健康和生活情境。

针对精神障碍者身体健康的系统综述显示，诊断遮蔽与不适配的医疗系统、专业知识不足、污名和沟通问题共同相关；该综述只纳入六项定性研究，因此可以提示机制和经验，不能估计诊断遮蔽在某个人群中的出现频率或比例。详见[[MolloyEtAl2023]]。

## 基线比标签更有用

降低诊断遮蔽的第一步是把“长期基线”和“新发变化”分开：

| 需要比较的内容 | 可询问的问题 |
|---|---|
| 起始时间 | 从小一直如此，还是近期开始？ |
| 变化速度 | 缓慢波动，还是数天至数周内明显改变？ |
| 情境 | 在所有环境都出现，还是只在特定感官、社交或任务情境出现？ |
| 功能影响 | 与本人以往相比，进食、睡眠、移动、沟通、自理或工作能力是否下降？ |
| 身体线索 | 是否有发热、疼痛、体重变化、月经变化、意识改变或局灶体征？ |
| 时间关联 | 是否与新药、调药、停药、感染、睡眠剥夺、物质使用或重大压力同步？ |

“不是新发”不表示不需要支持；“行为有环境触发”也不排除医学问题。基线比较只是帮助提出更好的鉴别问题。

## 完整评估应保留多种解释

NICE 成人孤独谱系指南建议在综合评估中同时了解早期发育史、当前功能、既往和当前的身体与精神障碍、其他神经发育状况、沟通困难和感官敏感，并评估可能的鉴别诊断与共现情况。[NICE CG142](https://www.nice.org.uk/guidance/cg142/chapter/recommendations)还提醒专业人员注意孤独谱系者身体疾病可能被低报或漏识别。

评估时不要只问“是不是神经类型造成的”，还要并行考虑：

1. 稳定神经特质及其合理调整需求；
2. 独立的新发精神或身体健康问题；
3. 环境不匹配、慢性压力或创伤的影响；
4. 药物、物质、睡眠和生命阶段变化；
5. 多种因素共同作用。

## 就诊时可以怎样减少信息丢失

当事人可以在条件允许时准备一页简短资料：

- 这次最希望解决的一个至三个问题；
- 与平常相比发生了什么变化；
- 症状的开始时间、频率和可能触发因素；
- 当前药物、近期调整和已知不良反应；
- 更容易沟通的方式，以及需要的感官或节奏调整；
- 是否希望由信任的人陪同或补充病史。

专业人员则应复述其理解、允许书面或替代沟通、把主诉逐项回应，并说明哪些判断已经确定、哪些仍需观察或检查。详见[[神经友好的健康评估]]。

## 证据边界

诊断遮蔽在精神障碍和智力障碍医疗中已有较多讨论，但针对不同神经殊异群体、不同科室和中国大陆服务系统的直接研究仍不足。孤独谱系常用一般精神健康量表的系统综述也提示，工具适用性、症状重叠和人群异质性会限制解释；不能因存在这些限制就否定量表，而应结合完整评估。[Halvorsen 等（2025）](https://doi.org/10.1007/s10803-024-06324-3)

中国大陆的《[精神障碍诊疗规范（2020年版）](https://www.nhc.gov.cn/yzygj/c100068/202012/b4305ace9e14440792eb76d29602c88a.shtml)》可用于核对本地诊断框架，但“诊断遮蔽”本身尚缺少统一的本地服务流程。页面中的预防原则属于通用医疗安全与可及性建议，不替代具体专科评估。

## 需要及时评估的变化

新的意识改变、首次或持续性抽搐、显著脱水或营养问题、快速功能下降、严重药物反应，或明显自伤与自杀危险，都不应仅用既有神经类型解释。此时应优先获得当地及时的医学或精神卫生评估。
