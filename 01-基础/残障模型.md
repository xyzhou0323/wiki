# 残障模型

**残障模型**（models of disability）是理解残障经验、解释相关困难并组织回应方式的理论框架。各模型关注身体与心智差异、活动限制、社会障碍、身份、文化及权利之间的关系，也影响研究、服务和政策怎样提出问题。医学模型侧重个体身心状况，社会模型侧重社会组织与排斥，关系取向考察个体与环境的互动；另一些模型则突出生活经验、集体认同和社会责任。

## 模型的形成与发展

[[RetiefLetsosa2018|Retief 与 Letsosa（2018）]]在实践神学的背景下综述了九种模型，说明模型如何影响对残障的定义、原因和责任归属，以及残障者的自我理解。《[斯坦福哲学百科全书：残障的定义与模型](https://plato.stanford.edu/entries/disability/)》则进一步讨论模型要解释什么，以及它们如何理解残障与不利益、福祉和社会回应的关系。

Retief 与 Letsosa（2018）的回顾将道德与宗教解释放在较早的历史背景中，并指出19世纪中叶以来医学解释的影响逐渐扩大。围绕残障的回应也涉及慈善救助、康复、劳动能力与福利分配，由此形成对个人处境、专业服务和社会资源的不同理解。

20世纪60—70年代的英国残障运动推动了社会模型的发展。UPIAS于1976年发表的《残障的基本原则》是这一转向的重要文献：残障者的活动限制与社会组织、隔离和排斥被联系起来讨论（Retief 与 Letsosa，2018）。问题由个体状况进一步扩展到环境、权力和共同生活的安排，少数群体与人权取向则分别突出群体地位、反歧视及权利保障。

围绕社会模型展开的讨论又形成了多条路径：关系取向和社会关系模型进一步分析身体经验与社会环境怎样共同影响生活；生物心理社会取向通过功能、活动和参与等层次组织评估，2001年发布的ICF是其重要应用。与此同时，Swain 与 French（2000）的肯定模型把积极身份与残障生活的价值带入讨论，文化研究关注残障观念和表征，Creamer（2009）的极限模型则在神学中重新考察具身限制与相互依赖。各取向的具体论述见《斯坦福哲学百科全书》、Retief 与 Letsosa（2018）及WHO（2002）的介绍。

这些发展线索彼此交叉，各种模型也持续共存于研究、服务和政策中。理解其关系，需要同时考察提出的历史背景、回应的问题，以及它们着重解释的经验或规范原则。

## 模型总览

| 模型 | 主要关注点 | 回应与实践取向 |
| --- | --- | --- |
| 道德/宗教模型 | 罪、惩罚、信仰考验、灵性或品格成长等宗教意义 | 通过宗教观念理解经历，并形成对残障者的态度与期待 |
| 慈善模型 | 受苦、需要及受助者与帮助者的关系 | 捐助、关怀、资源援助与专门服务 |
| 医学模型（个体模型） | 个体的损伤、疾病或功能障碍及其造成的活动困难 | 诊断、治疗、康复、技能训练与功能改善 |
| 经济模型 | 劳动能力、就业、收入与成本 | 评估和分配就业、福利及支持资源 |
| 社会模型 | 社会组织、环境障碍与歧视造成的限制和排斥 | 无障碍设计、反歧视、支持服务与集体行动 |
| 少数群体模型 | 残障者作为社会群体所经历的歧视、污名与排斥 | 民权保障、反歧视与集体组织 |
| 人权模型 | 人的尊严、平等、参与及相应的权利与责任 | 保障权利、参与决策，明确资源分配与制度责任 |
| 关系模型（互动模型） | 个体特征与具体任务、环境、资源之间的相互作用 | 结合个人体验调整环境要求与支持方式 |
| 社会关系模型 | 损伤带来的实际限制，以及社会压迫与排斥 | 同时关注身体体验、污名与环境，由当事人参与确定支持目标 |
| 生物心理社会模型 | 健康状况、身体功能、活动、参与和情境因素的互动 | 综合评估功能与参与，用共同语言协调服务和政策 |
| 肯定模型 | 残障生活中的积极身份、意义、自尊和集体文化 | 肯定生活价值，发展社群联系与残障文化 |
| 文化模型 | 语言、叙事、制度及日常实践如何塑造残障观念 | 分析文化表征，关注残障者自身的知识、艺术与叙事 |
| 极限模型 | 人类共同的具身限制、依赖与脆弱性 | 理解和回应具体限制，重视相互支持与身体多样性 |

## 宗教解释与医疗、救助取向

这些取向分别通过宗教意义、救助关系、个体功能和劳动能力理解残障，影响家庭、专业人员与公共机构怎样回应残障者的处境。

### 道德/宗教模型

道德或宗教模型（moral/religious model）通过罪、惩罚、信仰考验、灵性或品格成长等观念解释残障。Retief 与 Letsosa（2018）梳理了这些不同版本，说明它们如何赋予残障以宗教意义，并影响家庭、社群对残障者的态度和期待。这类解释在不同文化中具有不同的具体形式。

### 慈善模型

慈善模型（charity model）以受苦、救助和捐助关系理解残障，强调残障者需要关怀、资源和专门服务。其常见叙事围绕受助者与帮助者展开。

Retief 与 Letsosa（2018）同时介绍了对此模型的批评：当公众形象主要围绕怜悯和依赖组织时，残障者作为决策者、权利主体和社会参与者的位置可能受到遮蔽。这使服务如何呈现需要、如何分配决定权成为重要问题。

### 医学模型（个体模型）

医学模型（medical model）主要从个体的身体或心智状况解释残障，把损伤、疾病或功能障碍作为活动困难的重要原因。相应的回应通常围绕诊断、治疗、康复、技能训练和功能改善展开，研究也较多关注身体与认知层面的过程。

[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]讨论了这一取向在神经多样性语境中的影响：当差异主要被理解为个体缺陷时，社会组织与环境障碍可能较少得到关注。这也引出对改善目标的讨论，例如目标是减轻痛苦、增加行动能力，还是让表现更接近既定常态。[[常态范式]]进一步分析后一种评价尺度的形成。

### 经济模型

经济模型（economic model）从劳动、就业、收入和成本等角度分析残障。它关注身心状况与工作能力的关系，以及社会如何分配支持、福利和就业资源。

Retief 与 Letsosa（2018）讨论了这种取向在政策中的用途及其争议：以生产能力或成本收益为主要尺度时，参与、照护和生活质量的其他价值可能较难得到充分呈现。经济分析因而也涉及社会选择何种价值作为分配依据。

## 社会模型、集体行动与权利

残障者的集体行动使社会障碍、群体地位和自主决定成为重要议题。社会模型着重解释排斥，少数群体模型关注共同处境和民权，人权模型进一步讨论制度责任与权利保障。

### 社会模型

[[残障的社会模型|社会模型]]（social model）把残障放在社会组织和权力关系中理解。英国残障行动者组织 UPIAS 在1976年的纲领中，区分身体损伤（impairment）与社会施加的活动限制和排斥（disability）。这一取向将环境障碍、制度安排和歧视作为解释残障处境的重要对象。

例如，台阶与交通设计会影响轮椅使用者的出行，固定的交流规则和时间要求会影响不同沟通方式的人参与。回应由此指向无障碍设计、反歧视、支持服务及社会参与。社会模型也为残障者以集体身份组织起来、提出改变环境的要求提供了语言。

### 少数群体模型

少数群体模型（minority group model）将残障者理解为受到歧视、污名和排斥的社会群体。它关注共同处境如何形成，以及反歧视、民权保障和集体组织如何回应这些处境。

这一视角使研究能够从个别遭遇转向制度模式，例如哪些群体经常被排除在教育或工作机会之外，哪些社会评价影响其地位。它与[[神经殊异#与神经少数的关系|神经少数]]的政治讨论相联系。

### 人权模型

人权模型（human rights model）以人的尊严、平等和参与为出发点，将残障问题组织为权利、责任与政策的讨论。Retief 与 Letsosa（2018）依据 Degener 的研究，强调这一模型对公民与政治权利，以及经济、社会和文化权利的共同关注。

在这一取向中，残障者作为能够表达意愿、参与公共生活和提出权利要求的主体得到承认。无障碍、教育、就业、照护与支持，因而需要放在平等参与、资源分配和制度责任的框架中评价。社会模型较多说明排斥如何产生，人权模型则进一步明确回应这些处境的规范依据。

## 身体与环境的互动

身体经验与社会环境的关系成为进一步讨论的焦点：活动困难如何产生，个人体验与环境要求怎样联系，以及评估和支持如何同时关注这些因素。关系模型、社会关系模型和生物心理社会模型为这些问题提供了不同的分析方式。

### 关系模型（互动模型）

关系模型（relational model）或互动取向把残障理解为个体特征与具体环境之间的关系。同一种身心状况，在不同任务、资源和社会安排中，可能形成不同的活动机会与困难。分析因此同时关注个体的体验、环境的要求，以及两者如何相互作用。

[[Constantino2018|Constantino（2018）]]以口吃说明这种关系：费力的言语经验、对流畅表达的期待、讲话时间限制和他人的反应，会共同影响一个人的交流处境。理解这些关系，有助于分别考察表达需要、沟通环境和可选择的支持。

#### 社会关系模型

社会关系模型（social relational model）延续社会模型对压迫与排斥的关注，并将损伤效应纳入讨论。[[HeratyEtAl2023|Heraty 等（2023）]]在神经多样性肯定式生物医学研究的论述中采用这一框架：疾病和损伤可能带来实际活动限制，社会对损伤者的压迫性回应也会造成残障。他们据此主张，与孤独谱系者共同确定影响生活质量的体验，并同时考察身体过程、污名和环境匹配等因素。

### 生物心理社会模型

生物心理社会模型（biopsychosocial model）整合身体、个体与社会情境层面的分析。WHO（2002）的《国际功能、残障和健康分类》（ICF）入门指南将功能与残障描述为健康状况和情境因素互动的结果，并以此为分类框架的基础。

ICF分别描述身体功能与结构、活动、参与，以及与之互动的环境因素；其概念框架也考虑年龄、经验和应对方式等个人因素。这个框架有助于具体说明：一个人在什么任务、什么环境中遇到哪些困难，哪些条件能够促进参与。它为评估、服务沟通和政策讨论提供共同的描述语言。

## 身份、文化与具身经验

另一组讨论将注意力扩展到残障生活的意义与价值。肯定模型和文化取向关注身份、社群及表征；极限模型则从残障神学出发，考察身体限制、依赖与相互支持。

### 肯定模型

[[残障肯定模型|肯定模型]]（affirmation model）关注残障者对自身生活、身份及集体文化的积极理解。Swain 与 French（2000）提出的取向，将残障经验视为一种生活和体验世界的方式，重视自尊、社群联系及残障文化。

《斯坦福哲学百科全书》的讨论指出，这一取向改变了模型所着重解释的对象：除了困难与限制，也需要理解人们在残障生活中形成的意义、关系和价值。肯定模型由此与因果解释形成不同但可以交叉的分析层次。

### 文化模型

文化模型（cultural model）关注不同社会如何通过语言、叙事、制度和日常实践，形成有关残障与非残障的观念。Retief 与 Letsosa（2018）在综述中介绍了 Snyder 与 Mitchell 等人的工作，考察残障者被安排在何种文化位置，以及这些位置如何被赋予意义。

文化分析既关注机构、文学和影视中的残障表征，也关注残障者自身的知识、艺术与社群实践。它使讨论能够具体考察：谁在讲述残障生活，使用哪些故事，以及这些故事如何影响归属和参与。

### 极限模型

极限模型（limits model）来自残障神学。Retief 与 Letsosa（2018）介绍了 Creamer（2009）以具身体验和“极限性”（limit-ness）为中心的论述：限制是人类生活的普遍组成部分，人们会以不同方式经历身体、能力和环境的边界。

这一取向把残障经验放在人类共同的依赖、脆弱性和相互支持中理解，也关注人们如何评价、接纳或回应具体限制。它为神学和伦理讨论提供了理解身体多样性的路径。

## 模型与实践选择

模型会使不同的问题进入视野。关注身体经验，可以提出缓解痛苦和支持活动的问题；关注社会组织，可以识别环境和制度障碍；关注身份、文化与权利，则进一步涉及生活意义、参与决策与公共责任。

《斯坦福哲学百科全书》将因果解释与政策评价联系起来讨论：选择回应方式时，还需要考虑责任、公平、尊重及当事人的意愿。即使对困难的成因有相近理解，人们仍可能对由谁承担改变、怎样分配资源及应追求什么结果提出不同主张。

因此，应用模型的过程也包括明确实践目标。教育、工作和照护中的支持，可以具体说明它希望改善哪种体验、活动或参与机会，如何由受影响的人参与选择，以及怎样评价结果。

## 与神经多样性范式的关系

[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]将社会模型与关系取向视为理解神经多样性的重要资源：它们使注意、沟通和感官差异能够在个体与环境的关系中得到分析。肯定模型及文化取向则为理解神经殊异身份、自尊与社群生活提供了视角。

[[Dwyer2022|Dwyer（2022）]]提出的互动主义神经多样性方法，主张围绕福祉和生活质量确定支持方向，并让神经殊异者对相关目标拥有重要发言权。Heraty 等（2023）进一步展示了社会关系模型如何用于讨论生物医学研究与社群合作。各模型由此为[[神经多样性范式]]提供不同的概念资源，用来连接具体体验、社会障碍和共同决定支持目标的实践。
