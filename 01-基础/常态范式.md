# 常态范式

**常态范式**（normalcy paradigm）是以特定的“正常”身心模式评价神经认知差异，并将偏离常态默认视为病理的框架。[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]用这一术语分析常态、健康及非典型性之间的关系：当符合常态被视为健康和良好功能的标准时，差异便容易成为需要纠正的对象。这个概念关注科学研究与日常文化中的基本假设，以及这些假设如何影响问题的提出、经验的解释和改善目标的选择。相关讨论与Nick Walker提出的**病理学范式**（pathology paradigm）密切联系，后者着重分析正常心智、内在缺陷和正常化目标之间的关系。

## 常态、健康与理想表现

理解常态范式，可以从几种经常被联系起来的判断入手：

| 判断所关注的问题 | 含义 | 可以进一步追问的内容 |
|---|---|---|
| 某种表现是否常见 | 相对于某个人群或参照范围的典型程度 | 比较对象如何选择，差异怎样分布 |
| 某种状态是否影响健康与福祉 | 个体的身体、心理体验和生活状况 | 是否涉及痛苦、活动困难或支持需要 |
| 某种表现是否值得追求 | 对能力、行为和生活方式的价值评价 | 谁设定目标，目标服务于何种需要 |

在Chapman与Fletcher-Watson的分析中，常态范式把这些判断紧密捆绑：某种典型模式既成为解释差异的基准，也成为评价人的能力和决定改变方向的尺度。由此，接近常态本身便可能被当作改善。

[[MullerKosmarovChapman2026|Müller-Kosmarov 与 Chapman（2026）]]还强调能力排序这一面向：人们按照既定的心智功能标准被排列为较低、正常或较高的等级，更高排名被赋予更优越的价值。这个分析把注意引向统计描述如何转化为理想，以及评价尺度如何组织社会中的机会与地位。

## 病理学范式

Nick Walker 在[*Throw Away the Master’s Tools: Liberating Ourselves from the Pathology Paradigm*](https://neuroqueer.com/throw-away-the-masters-tools/)中，将“病理学范式”（pathology paradigm）概括为一组基本假设：存在一种正确或健康的神经认知方式，明显偏离这种方式的人则被视为具有内在缺陷。（文章初版发表于2012年，作者网站提供的是2013年修订版。）

### 正常心智与内在缺陷

Walker把这组前提进一步归纳为两项：

1. 人类大脑与心智存在一种正确、正常或健康的配置与运作方式，或者应当落在一个相对狭窄的正常范围内。
2. 当一个人的认知、思考和行为明显偏离这个标准时，这种偏离被解释为此人自身出了问题。

在Walker的论述中，这两项假设为病因解释、分类和干预提供了共同前提。不同倡导者可能在差异从何而来、应采取何种措施等问题上相互争论，同时共享以正常心智为理想、以偏离为缺陷的出发点。病理学范式因此涉及一整套解释方式，贯穿研究、服务、家庭期待与公共叙事。

### 缺陷归因与正常化目标

这一框架把典型表现作为衡量个体的尺度，将人与环境、人与人之间的困难主要定位在偏离标准的一方。Walker以沟通为例：当[[神经典型]]者和孤独谱系者彼此难以理解时，解释容易集中于孤独谱系者的沟通或同理心缺陷。这里值得分析的是，同一次互动中各方的表达、理解和环境条件，如何被纳入原因说明。

缺陷归因也参与决定改善目标。如果差异本身被看作问题，减少差异、使表现接近典型，便成为干预成功的直观尺度。[[Dwyer2022|Dwyer（2022）]]以自我刺激行为说明这种目标取向：把减少这类行为设为目标，与调整环境、减轻压力并由此改变行为，体现了不同的问题理解和评价依据。

这使病理学范式的分析能够同时关注三个环节：以何种认知方式作参照，如何解释偏离，以及为什么把某种改变视为进步。研究和支持措施的具体内容，都可能受到这些前提的组织。

### 病理化语言与自我理解

Walker进一步讨论语言如何固定这些判断。“症状”“受损”等词把经验放进病理叙事；当某一认知方式成为默认标准时，“高功能”和“低功能”又可能把接近这一标准的程度写成对整个人的总体评价。语言在这里同时承担描述、分类和价值排序的作用。

这种叙事也可能进入[[神经殊异]]者的自我理解。Walker用“内化压迫”讨论人们如何吸收有关自身缺陷的社会信息，并以这些信息评价自己的身份与可能性。[[Dwyer2022|Dwyer（2022）]]对缺陷观念和预期的讨论，则把这一问题联系到教育与支持关系：怎样描述一个人，会影响周围人对其学习、参与和发展机会的期待。

## 术语来源与相关概念

### 从病理学范式到常态范式

Chapman与Fletcher-Watson（2026）沿用这一批判方向，选择了“常态范式”这一名称来突出将常态等同于健康、将非典型性等同于病理的推理。他们把回应的重点放在[[去病理化|克服默认病理化]]，并依据具体经验讨论健康、残障与支持。

### 与医学模型和神经规范性的关系

这几个概念在讨论中相互联系，各自强调的层次如下：

| 概念             | 主要关注                                |
| -------------- | ----------------------------------- |
| 常态范式           | 解释和评价神经认知差异时采用的基本假设，尤其是常态与健康的绑定     |
| 病理学范式          | Walker对相近问题的命名，突出把非典型认知方式理解为内在缺陷的取向 |
| [[残障模型\|医学模型]] | 对残障的解释方式，主要将问题定位于个体身心的损伤或功能障碍       |
| [[神经规范性]]      | 特定认知和行为方式如何成为社会期待，并影响制度、互动与资源分配     |

用这些层次理解同一情境，可以分别考察评价依据、问题的归属，以及社会如何回应差异。例如，一项沟通支持的目标可能涉及表达需要、参与互动，也可能涉及表现是否接近惯常的社交方式；常态范式的分析关注这些目标如何被选择和排序。

## 历史分析

[[Chapman2023|Chapman（2023）]]在《正常帝国》中，将常态标准的发展放在资本主义生产、能力测量及社会分类相互作用的历史中考察。这是一种关于常态与权力关系的历史解释：工作组织需要怎样的劳动者，哪些能力受到奖励，以及哪些人被排除，会影响人们怎样理解正常与异常。

### 工业劳动与能力标准

Chapman讨论工业生产中的工作日、劳动节奏和效率要求如何逐渐标准化，并由此形成对劳动者身体与心智的共同期待。在这一叙述中，生产能力参与塑造了社会对独立、合格和有价值的人的理解；与既定要求不相适应的人，则更容易面临分类、隔离及机会受限。

### 心理测量与等级秩序

Chapman将Francis Galton的能力排序、心理测量和优生学思想视为病理学范式形成的重要环节，并讨论这些思路如何经由Emil Kraepelin等人进入精神病学与心理科学。其论证关注的是：社会中的等级和理想，如何借助测量与分类，被表述为有关人类自然差异的知识。

在Chapman的解释中，资本主义的制度逻辑与这一知识框架相互强化。更具体的统计史、分类史及优生学讨论，见[[常态的发明]]、[[优生学]]和[[神经多样性与资本主义]]。

## 科学研究与文化中的运作

Chapman与Fletcher-Watson（2026）将常态范式放在科学与文化两个相互联系的层面讨论。研究中的分类和解释会影响公共理解，日常生活中的价值期待也会进入研究问题、测量工具及评价指标。

在研究中，这种关系体现在比较组的选择、差异的命名以及干预结果的定义。例如，研究可以询问某种支持是否让行为更接近典型表现，也可以询问它是否改善沟通、减轻痛苦或增加参与机会。不同问题会使不同经验和结果进入关注范围。

在文化中，这种关系体现在人们如何叙述[[神经殊异]]者的生活：哪些行为被理解为得体或成熟，哪些经历被写成成功、失败或悲剧，以及社会期待人们改变什么。科学分类与文化叙事由此共同塑造对差异的认识。

[[Botha2025|Botha（2025）]]从科学哲学角度讨论研究中的本体论、知识观、方法与价值目标。她以孤独谱系研究为例，主张通过批判实在论和社群参与，结合物质经验、社会情境与当事人的知识。这个讨论进一步说明，检视范式也涉及谁能够提出问题、哪些经验进入证据，以及研究为谁服务。

## 与神经多样性范式的讨论

[[神经多样性范式]]推动的转变，涉及如何解释差异，也涉及用什么尺度评价改变。Walker强调认知多样性的价值；Chapman与Fletcher-Watson（2026）以“肯定复杂性”和“将神经规范性政治化”说明其方向，将不同认知经验、支持需要和制度安排纳入讨论。

[[Dwyer2022|Dwyer（2022）]]提出的互动主义神经多样性方法，把残障放在个体特征与环境的互动中理解。依照这一立场，支持可以涉及个体、环境或二者的改变，评价重点是福祉、生活质量及本人对目标的参与。

这种讨论把研究和实践带向几个具体问题：当事人希望改变什么，哪些环境要求造成困难，支持是否增加自主与参与，以及结果如何由受影响的人共同评价。常态范式因而提供了一种审视既有尺度的方式，使原先被默认的目标成为可以讨论和重新选择的对象。
