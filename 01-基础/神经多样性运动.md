# 神经多样性运动

**神经多样性运动**（neurodiversity movement）是由[[神经殊异]]者及其盟友参与的社会与政治运动，争取神经认知差异者的平等、尊严、自主决定和社会参与。它将接纳差异与获得实际支持联系起来，推动当事者参与研究、服务和公共政策的制定，并关注社会环境、制度和文化怎样影响人们的生活。

## 运动的定位

[[Walker2014|Walker（2014）]]将[[神经多样性]]、[[神经多样性范式]]和神经多样性运动分别用于描述人类心智差异、理解差异的理论立场，以及围绕这些问题的集体行动。运动中的社群、组织、研究者及其他参与者通过不同方式开展倡权，在关切的议题、行动策略和对范式的理解上存在差异。[[NeemanPellicano2022|Ne’eman 与 Pellicano（2022）]]据此强调，应通过运动内部的讨论和共同决定来处理这些分歧。

运动的重要基础是1990年代形成的孤独谱系自我倡权社群。[[BothaEtAl2024|Botha 等（2024）]]指出，神经多样性的概念和理论在社群交流中得到集体发展，并逐步扩展到更广泛的神经殊异经验。具体的组织发展、人物、事件和术语传播见[[神经多样性运动史]]。

## 主要诉求

### 参与和自主决定

“Nothing About Us Without Us”（我们要参与关于我们的决定）表达了残障自我倡权的参与原则。孤独谱系自我倡权网络（[ASAN](https://autisticadvocacy.org/about-asan/what-we-believe/)）将其解释为：讨论孤独谱系及作出有关决定时，需要有孤独谱系者的参与，让政策与服务回应当事者的生活。

这一诉求涉及谁能提出问题、解释经验、选择支持方式和评价结果。它也连接个人层面的自我倡权与集体层面的公共参与：个人表达需要、偏好和生活目标，组织及社群则推动这些声音进入研究和制度决策。

### 接纳、尊严与公共叙事

运动重视神经殊异者作为社会成员的价值，以及人们理解和表达自身经验的权利。[[Sinclair1993|Sinclair（1993）]]要求家长看见现实中的孤独谱系孩子，并在尊重其存在方式的基础上学习沟通、建立关系和提供帮助。这种论述将当事者的经验与身份放到公共讨论的中心。

接纳也体现在日常交往和公共表达中，包括尊重不同沟通方式、兴趣和感官需要，审视将差异直接解释为缺陷的语言，以及让神经殊异者参与讲述自己的生活。相关理论讨论见[[去病理化]]、[[神经规范性]]和[[常态范式]]。

### 支持获取与社会参与

接纳与具体支持共同构成倡权工作。ASAN的立场说明提到沟通支持，以及物理治疗、言语治疗和作业治疗等服务，并强调支持人员所需的工作条件。支持的内容由具体困难和生活目标来确定，包括学习、交流、日常活动与参与社群所需的帮助。

[[ChapmanBovell2022|Chapman 与 Bovell（2022）]]在讨论治疗争议的章节手稿中，主张结合当事者及其亲近者的视角，以福祉和自主来考察干预的益处。这使服务是否容易获得、能否改善生活、怎样尊重意愿，成为与接纳差异相联系的实践问题。

## 组织与行动方式

运动通过相互联系的社群和组织开展工作。以下形式概括了个人、社群、倡权组织与研究者之间的不同连接方式：

| 行动形式        | 主要工作                  | 例子或涉及的议题                       |
| ----------- | --------------------- | ------------------------------ |
| 社群支持与自我倡权   | 分享经验、互助、表达需要，建立社群联系   | AWN为孤独谱系女性及其他边缘性别群体提供社群支持与资源   |
| 组织倡导与公共政策参与 | 组织社群、培养倡权能力，分析和参与公共政策 | ASAN的领导力培养、政策分析与公共教育           |
| 参与研究与知识生产   | 将生活经验带入研究问题、解释及实践讨论   | AASPIRE的社群参与式研究，以及研究者与自我倡权者的合作 |
| 文化与公共表达     | 通过写作、公共讨论和社群叙事表达身份与诉求 | Sinclair的倡权写作，以及对语言、表征和接纳的讨论   |

ASAN在[组织介绍](https://autisticadvocacy.org/about-asan/who-we-are/)中列出倡权、出版、研究及政策工作；孤独谱系女性与非二元网络（[AWN](https://awnnetwork.org/about/)）则在其使命中强调社群支持和交叉处境。这些实例体现了不同组织的工作侧重。AASPIRE则采用社群参与式研究（CBPR），通过共享决定权和适配沟通方式开展合作（[[NicolaidisEtAl2011|Nicolaidis 等，2011]]）。

运动也参与改变知识如何产生。Chapman 与 Bovell（2022）讨论了孤独谱系者被排除在相关知识生产之外的问题，以及研究中的缺陷预设如何影响结果的解释。将生活经验带入研究，因而既涉及增加参与者，也涉及研究什么、使用怎样的概念、由谁判断研究是否有益。[[参与式行动研究]]提供了将这一参与诉求落实到研究过程中的一条路径：社群成员与研究者共同确定问题、开展研究，并将发现转化为回应社群需要的行动（[[LloydEvans2023|Lloyd-Evans 等，2023]]）。研究中的权力分配和学科发展另见[[神经多样性与民主研究]]和[[神经多样性研究]]。

## 与残障权利运动的关系

[[NeemanPellicano2022|Ne’eman 与 Pellicano（2022）]]将神经多样性运动放在更广泛的残障政治中理解，指出它与独立生活、发展性残障自我倡权及其他残障社群之间的联系。这些传统为自主生活、集体组织和抵抗外部支配提供了思想与实践资源。

[[残障的社会模型]]使环境障碍和排斥成为分析对象，其他[[残障模型]]则进一步涉及身体经验、互动、身份和权利。在这一背景下，神经多样性倡权可以同时追求对差异的尊重、残障者的权益以及支持资源的改善。

Ne’eman 与 Pellicano也提醒，新的神经多样性语言应维持与残障社群的联系，使共同的政策诉求和既有的倡权经验能够被理解和使用。它们之间的关系涉及共同组织和资源分配，也涉及如何描述自身处境。详见[[神经多样性与残障]]。

## 内部批判

### 代表性与参与条件

参与原则需要落实为能让不同沟通方式、支持需求及社会处境的人表达意见的条件。ASAN的立场说明包含对辅助与替代沟通（AAC）的支持；AWN的使命则特别关注性别与其他交叉经验。由此，讨论代表性时，需要具体考察谁能够进入讨论、表达意见需要哪些帮助，以及组织如何回应不同成员的需要。

这一问题与[[神经多样性与交叉性]]相连：同一诊断或身份之内，人们的资源、机会、生活经历及面对的障碍也可能有显著差异。

### 运动的范围与社群选择

Ne’eman 与 Pellicano（2022）区分了神经多样性作为广泛残障权利立场的用法，以及它对正常化、治愈和预防目标提出特定批评的用法。二者会带来不同的运动范围，也会影响其他社群怎样理解这些主张。

作者据此强调，各社群应有机会讨论哪些理念适合自身处境、希望追求什么目标。跨社群合作建立在对彼此需要和自主决定的理解之上，参与者也可以围绕共同议题合作，同时保留不同立场。

### 与医学模型的复杂关系

治疗与支持的讨论集中于具体目标、证据、代价和决定权。Chapman 与 Bovell（2022）以[[应用行为分析]]为案例，分别考察疗效、正常化或社会控制、创伤与福祉、自主权，并提出让神经典型者与神经殊异者共同讨论何种结果对谁有益、出于什么目的、适用于什么情境。

这类讨论要求把“改善”具体化：一项支持希望缓解什么困难，是否有助于当事者的生活，如何对待意愿和偏好，以及怎样评价可能的伤害。更详细的干预与伦理分析见[[ASD干预]]。

## 不同社会情境中的实践

[[ChengEtAl2023|Cheng 等（2023）]]结合在欧洲、亚洲和非洲开展研究或自我倡权的经验，讨论社群主导的权利运动怎样回应当地的文化、语言、资源和政治条件。

作者举出的例子具有不同侧重：埃塞俄比亚的实践涉及诊断和物质资源的不足，以及家庭、社群中的接纳和归属；印度的参与式设计尝试使用当地语言与熟悉的概念，促进理解和包容；香港的例子则涉及学业竞争、社会从众期待与包容教育的尝试。这些实践展示了接纳、参与和权利诉求怎样在具体环境中获得不同表达。

Cheng等人主张通过多向交流理解各地社群已经形成的知识和实践，让本地参与者共同确定问题及回应方式。国际合作由此涉及资源和决定权如何分配，以及怎样使研究与倡权回应当地生活。
