# 神经多样性范式

**神经多样性范式**（neurodiversity paradigm）是理解、研究和回应神经认知差异的一组科学、伦理与政治立场。相关论述肯定[[神经多样性]]的价值，考察差异与身体、环境和社会关系的联系，并将福祉、自主决定及社会参与作为研究和支持的重要目标。它也关注谁有权解释这些经验、定义需要改变的问题，以及决定什么算作改善。

## 范式、框架与方法群

[[Walker2014|Walker（2014）]]将神经多样性范式描述为理解人类心智差异的特定视角，并将其与差异本身及围绕权利开展的[[神经多样性运动]]区分。这一视角涉及对人的价值、认知标准和社会权力关系的判断，为研究、教育和倡权等实践提供思想资源。

“范式”也表达了改变科学与文化中基本假设的意图。[[MullerKosmarovChapman2026|Müller-Kosmarov 与 Chapman（2026）]]借助科学哲学中的范式概念，说明这些假设会影响问题如何提出、数据怎样解释，以及人们怎样理解神经殊异者的社会位置。[[ChapmanFletcherWatson2026|Chapman 与 Fletcher-Watson（2026）]]同样从科学与文化两个层面讨论这种转变。

不同作者对理论的表述和具体主张有所不同。[[Dwyer2022|Dwyer（2022）]]采用“神经多样性方法群”（neurodiversity approaches），强调残障解释、干预和适用范围等议题中的实质性分歧。Müller-Kosmarov与Chapman则讨论了“范式”与“框架”等称谓的不同含义：前者突出了转变的深度与广度，也带来了如何理解科学变迁的哲学问题。

## 范式关注的问题

相关论述从理解差异延伸到研究、支持和公共生活。下表概括其中几项相互联系的问题，具体主张在后文按作者展开：

| 问题 | 讨论焦点 |
| --- | --- |
| 怎样理解差异？ | 神经认知方式的多维性、具身经验，以及个体与集体生活的联系 |
| 怎样解释残障？ | 身体特征、活动要求、环境条件与社会障碍如何共同影响生活 |
| 什么需要改变？ | 哪些体验、行为或环境造成痛苦、限制行动或妨碍参与 |
| 支持追求什么？ | 福祉、生活质量、自主决定及具体参与机会 |
| 谁参与判断？ | 当事者、社群、支持者及专业人员怎样共同确定问题和目标 |
| 研究怎样开展？ | 研究议程、概念、测量、结果解释与社群参与如何组织 |

## 差异的价值与复杂性

Walker（2014）将神经多样性视为自然且有价值的人类多样性，并关注不同认知方式之间的社会权力关系。[[PellicanodenHouting2022|Pellicano 与 den Houting（2022）]]进一步将对多样性的肯定与人的尊严联系起来：无论某种差异是否带来集体益处，人都应因其自身而受到尊重。这使社会接纳与资源支持具有独立于生产能力或特定优势的伦理依据。

Chapman与Fletcher-Watson（2026）以**肯定复杂性**（affirm complexity）概括其理论方向之一。他们强调同一诊断类别内部的异质性、人的生命历程，以及不同个体在身体、认知、环境和支持需要上的差异。研究与实践由此需要容纳多种经验，并具体理解哪些条件能使人们生活得更好。

Müller-Kosmarov与Chapman（2026）还从个体与集体两个层面讨论心智功能：不同认知方式可以在合作、知识和共同生活中发挥作用。这样的分析将差异放入人与人之间的关系中考察，扩展了以个体能力排序理解功能的视野。

## 神经规范性与评价标准

Chapman与Fletcher-Watson（2026）的另一项主张是**将神经规范性政治化**（politicize neuronormativity）。[[神经规范性]]涉及哪些认知、情绪、感官或行为表现被视为理想，以及这些评价如何影响社会位置和机会。作者要求把这些标准放回其社会、文化与历史条件中，考察它们如何产生、服务于哪些安排，以及由谁承担适应的代价。

这也涉及[[常态范式]]所讨论的正常、健康与理想功能之间的联系。对于学习、交流或工作的困难，需要具体说明评价依据：某种表现是否造成痛苦或活动限制，环境是否容纳不同方式，所追求的改变与谁的目标相符。Müller-Kosmarov与Chapman（2026）将此概括为范式的概念与规范两个层面，即如何理解心智功能，以及据什么理由评价差异和选择回应。

## 残障解释与支持目标

### 个体与环境的互动

Dwyer（2022）提出一种互动主义的神经多样性方法，将残障理解为个体特征与环境共同作用的结果。这样的解释同时关注身体体验、功能限制、环境要求和歧视等因素，支持也可以围绕个人技能、环境调整或二者的结合展开。具体的模型区别见[[残障模型]]。

在这一方案中，选择支持方式的依据是它怎样改善生活质量。个人与环境的作用需要一起分析，目标则结合具体情境中的困难、活动和当事者意愿来确定。Dwyer以自我刺激行为说明目标的差别：改善环境、减轻压力后某种行为随之减少，与把压制该行为本身作为目标，具有不同的伦理含义。

### 福祉、自主与生活质量

Dwyer反对以正常化或“治愈”残障者为目标的干预，同时讨论了教授技能、使用药物缓解困难及改变环境等支持。这是作者所提出的规范性方案，需要与其他作者的具体论述结合理解。

Chapman与Fletcher-Watson（2026）将医疗照护、社会支持和对不同存在方式的理解共同纳入肯定复杂性的要求。他们以癫痫、痴呆等情况说明，人的神经殊异经验可能包含实际疾病和照护需要；研究、服务和政策应回应不同情境中的需要。关于支持和干预的具体伦理讨论见[[ASD干预]]，差异与残障身份的联系见[[神经多样性与残障]]。

## 研究问题与知识生产

[[PellicanodenHouting2022|Pellicano 与 den Houting（2022）]]从孤独谱系科学出发，讨论了传统研究中过度聚焦缺陷、侧重个体而忽略环境，以及当事者声音被排除等问题。他们主张扩大研究对象与解释视野，让孤独谱系者参与研究议程及相关决定。这样的改变同时涉及研究什么、如何理解结果，以及知识由谁共同生产。

[[HeratyEtAl2023|Heraty 等（2023）]]将这些问题带入生物医学研究。他们主张与社群共同确定有意义的研究问题和结果指标，在项目范围设定及申请资助的早期开展参与，并共同解读研究发现。他们还讨论了研究叙事如何影响整个群体，以及资助和学术制度怎样支持持续合作。

在这些论述中，生活经验是确定问题、理解测量和评价结果的重要知识资源。关于研究中的参与与决定权，见[[神经多样性与民主研究]]；共同研究并推动行动的方法讨论见[[参与式行动研究]]，更广的学科与方法论讨论见[[神经多样性研究]]。

## 适用范围与诊断分类

Dwyer（2022）将适用范围视为尚在讨论的问题。不同人对某种特征与自身身份、痛苦或生活目标的关系，可能有不同理解；这些差异会影响人们希望获得什么支持，以及神经多样性方法与医学方法如何结合。

诊断分类也同时承担多种功能。Dwyer指出，同一类别内部具有异质性，类别之间可能共现；类别又能帮助人们组织经验、形成社群、开展研究和取得支持。范式中的分类讨论因而涉及如何描述维度性差异，以及怎样使分类回应实际经验和社会需要。相关术语范围见[[神经殊异]]。

## 科学哲学与进一步讨论

[[Botha2025|Botha（2025）]]从社区心理学出发，提出批判实在论作为理解孤独谱系及开展社会正义研究的一种科学哲学资源。它承认现实中的结构和因果作用，同时将科学知识理解为受社会条件、观察方法和解释影响、可以修正的认识。Botha据此讨论如何结合物质处境、社会不平等和当事者参与，开展能够改善生活的研究。

Müller-Kosmarov与Chapman（2026）则将神经多样性哲学的讨论延伸到知识、具身体验、身份及政治伦理等方向。这些研究继续追问：哪些经验能成为知识，诊断与自我理解怎样联系，以及支持和公共生活应怎样组织。相关专题见[[知识不正义]]、[[去病理化]]与[[神经多样性与交叉性]]。理论的社群背景和组织发展另见[[神经多样性运动史]]。
